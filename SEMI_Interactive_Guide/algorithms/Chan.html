분산된 Batch나 Stream Window의 count, mean, M2를 수치적으로 안정적으로 병합해 평균과 분산을 계산합니다.

Streaming KPIDeveloper

개발 기능 요약

장비별, Chamber별, 시간창별 KPI를 병렬 집계한 뒤 상위 KPI 시스템에서 정확하게 합칠 때 유용합니다.

핵심 로직: delta = meanB - meanA; n = nA + nB; mean = meanA + delta * nB / n; M2 = M2A + M2B + delta^2 * nA * nB / n

GEM300 실행 계층E40/E87/E90/E94가 Lot, Carrier, Substrate, Job 단위의 생산 문맥을 붙입니다.
EDA 수집 계층E120/E125/E134/E164가 고속, 다중 Client, Metadata 기반 수집을 제공합니다.
TC / EAP장비 제어, Recipe Download, Start/Stop, Interlock, Host Command를 담당합니다.
EES / APC / FDCFault Detection, Run-to-Run Control, 모델 기반 분석, 설비 성능 추적을 담당합니다.
KPI 시스템OEE, MTBF/MTTR, Yield, Cycle Time, Alarm Pareto, 분위수 지표를 실시간 집계합니다.

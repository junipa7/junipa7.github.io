1장. SEMI E39 (Object Services) 개요

SEMI E39는 장비 내부의 다양한 데이터와 요소를 객체 지향(Object-Oriented) 개념으로 관리하기 위한 공통 인터페이스입니다. GEM300 체계 내에서 Carrier(E87), Substrate(E90), Process Job(E40) 등 수많은 객체가 생성되는데, 이 객체들의 속성을 묻고(Get), 바꾸고(Set), 만들고(Create), 지우는(Delete) 공통 문법을 제공하는 기반 표준입니다.

1. 왜 Object Services가 필요한가?

E39가 없다면 Carrier를 조회하는 명령어, 웨이퍼를 조회하는 명령어, 작업 지시를 변경하는 명령어가 각각 SECS-II의 서로 다른 Stream과 Function(예: S1x, S2x, S7x 등)으로 난립했을 것입니다. E39는 이를 Stream 14 (Object Services)로 통일하여, 객체의 이름표(ObjID)와 속성 이름(AttrID)만 알면 어떤 객체든 일관된 방식으로 다룰 수 있게 만들었습니다.

2장. 핵심 개념과 객체 지정 방식 (Addressing)

1. 객체 식별자 (Object Identifier, ObjID)

장비 내의 모든 객체는 고유한 식별자를 가집니다. 예를 들어, 1번 Load Port에 있는 FOUP의 ObjID는 "CST001"일 수 있고, 특정 작업 지시는 "PJ1024"일 수 있습니다. 호스트는 항상 이 ObjID를 통해 특정 객체를 지목합니다.

2. 속성 (Attributes)

각 객체는 고유의 속성들을 가집니다. 예를 들어 Carrier 객체는 'SlotMap', 'UsageType', 'Capacity' 등의 속성을 가지고, Substrate 객체는 'SourceDestinationInfo', 'Status' 등의 속성을 가집니다.

객체 지향 프로그래밍(OOP)의 개념과 매우 유사합니다. 장비는 클래스(Class)의 인스턴스(Instance)를 생성하고, 호스트는 객체의 프로퍼티(Property)에 접근하는 구조입니다.

3장. Stream 14 (S14Fx) 핵심 메시지 분석

E39는 Stream 14를 사용하여 통신합니다. 실무에서 가장 많이 사용되는 핵심 Function들입니다.

메시지 (S14Fx)메시지 이름기능 설명 및 실무 적용
S14F1 / S14F2 Get Attribute Request / Data 호스트가 특정 객체(ObjID)의 특정 속성(AttrID) 값들을 조회합니다. "이 FOUP(Carrier)의 슬롯 맵(SlotMap) 정보를 줘"라고 요청할 때 씁니다.
S14F3 / S14F4 Set Attribute Request / Acknowledge 호스트가 객체의 속성을 강제로 변경합니다. "이 웨이퍼의 상태를 '공정 불가(Scrap)'로 바꿔라"와 같은 지시를 내립니다.
S14F9 / S14F10 Create Object Request / Acknowledge 새로운 객체를 생성합니다. E40/E94에서 호스트가 장비에게 새로운 Process Job이나 Control Job 지시서를 내려보낼 때 이 메시지를 사용하여 객체를 Instantiate(생성) 합니다.
S14F11 / S14F12 Delete Object Request / Acknowledge 작업이 다 끝난 객체(Job)를 메모리에서 삭제합니다. 객체가 너무 많이 쌓이면 장비 메모리에 부하가 가므로 주기적인 정리가 필요합니다.

4장. 실무 적용 체크포인트

에러 코드(ACKC14) 분석 S14F9(객체 생성) 전송 후 장비가 에러(ACKC14 != 0)를 반환할 때, 단순히 '실패'로 넘기면 안 됩니다. ERRCODE와 ERRTEXT를 파싱하여 속성 이름이 틀렸는지, 권한이 없는지, 포맷(ASCII/Binary)이 어긋났는지 정확히 트러블슈팅해야 합니다.
이벤트 기반의 속성 동기화 호스트가 주기적으로 S14F1(GetAttr)을 던져서 상태를 조회하는 것(Polling)은 네트워크를 고갈시킵니다. E39는 속성이 변할 때 이벤트를 던지는 기능이 있으므로, 가급적 CEID 기반의 S6F11 동적 이벤트 리포팅과 연계하여 상태 변경을 수신해야 합니다.

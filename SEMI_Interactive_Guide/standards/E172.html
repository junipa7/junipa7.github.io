SEMI E172 - SECS Equipment Data Dictionary

SECS/GEM 장비 데이터 사전을 XML 기반으로 표현하는 규격입니다.

Data DictionaryGuide & Developer

기능 요약

TC/EAP, Simulator, Test Tool이 장비 메시지와 변수 정의를 자동 로딩하도록 돕습니다.

원문 표준 문서는 SEMI 공식 표준 문서 또는 SEMIViews에서 개정판을 확인해야 합니다. 개발 및 업무 적용 포인트를 함께 확인하세요.

데이터 흐름 (DFD)

업무 적용 체크포인트

적용 위치설비, TC/EAP, EES/APC/FDC, MOS/MES, KPI 시스템 중 관련 계층을 확인합니다.
검토 대상표준 번호, 개정판, 고객 사양서, 벤더 구현 범위, 예외 승인 항목을 함께 봅니다.
운영 영향장비 상태, 생산 문맥, 데이터 품질, 보안 요구사항이 상위 지표에 미치는 영향을 검토합니다.

EDA / Interface A Overview

EDA는 SECS/GEM 이벤트 보고보다 더 구조화된 고속 데이터 수집 체계입니다. 장비 모델을 발견하고, 수집 계획을 만들고, 품질과 메타데이터를 함께 관리합니다.

E120 ModelE125 ServicesE132 AuthE134 DCME151/E160 QualityE164 Metadata

1. EDA 데이터 수집 파이프라인

E132접속 권한

Client 인증과 권한을 확인해 장비 데이터 접근 범위를 제한합니다.

E120장비 모델

Module, Chamber, Sensor, Parameter 구조를 공통 모델로 표현합니다.

E125서비스 호출

Client가 장비 모델과 데이터 서비스를 조회하고 구독합니다.

E134수집 계획

Trace, Event, Exception 같은 Data Collection Plan을 설정합니다.

E151/E160데이터 품질

값이 믿을 만한지, 누락/지연/비정상 상태인지 함께 전달합니다.

E164공통 메타데이터

데이터 의미, 단위, 출처를 일관되게 해석하게 돕습니다.

2. 계층으로 이해하기

Access
E132장비 데이터에 접근할 수 있는 Client인지 인증하고 권한 범위를 결정합니다.
Model
E120 + E164장비 구조와 메타데이터를 시스템이 해석 가능한 형태로 제공합니다.
Service
E125모델 조회, 데이터 구독, 이벤트 수신 같은 EDA 서비스의 기본 통신 방식을 제공합니다.
Collection
E134어떤 데이터를 어떤 조건과 주기로 수집할지 계획하고 관리합니다.
Quality
E151 + E160데이터 값뿐 아니라 품질 상태를 함께 전달해 FDC/APC/EES가 신뢰도를 판단하게 합니다.

4. 먼저 잡아야 할 관점

모델을 알아야 수집도 안정됩니다.

E120/E164가 장비 데이터의 주소록과 의미 사전 역할을 합니다.

수집 계획은 운영 계약입니다.

E134는 어떤 데이터를 어떤 품질과 조건으로 받을지 정하는 운영 약속입니다.

품질 정보는 값만큼 중요합니다.

FDC/APC는 값 자체보다 그 값이 유효한지, 늦었는지, 대체값인지 함께 판단해야 합니다.

1장. SEMI E87 (Carrier Management) 개요

SEMI E87은 300mm(12인치) 팹 자동화에서 웨이퍼를 담는 용기인 FOUP이나 카세트(Carrier)의 움직임과 상태를 추적 및 제어하는 표준입니다. OHT(Overhead Hoist Transport)나 AGV 같은 반송 로봇이 Load Port에 Carrier를 내려놓는 순간부터, 장비가 이를 인식하고 조작한 뒤 다시 반출하기까지의 전체 라이프사이클(Carrier Management State Model)을 관리합니다.

2장. Carrier 상태 모델 (CMS, Carrier Management State)

장비의 Load Port에 올려진 FOUP은 다음과 같은 복잡한 상태 트리를 거칩니다.

1. ID Status (식별 상태)

FOUP이 Load Port에 도착(Carrier Arrived)하면 장비는 바코드나 RFID(보통 S24/E99 표준 사용)를 읽어 FOUP의 ID를 확인합니다.

  • ID Not Read: 아직 읽지 않음.
  • Waiting For Host: 읽은 ID를 호스트에 보고하고 "이 FOUP 맞아?"라고 승인을 대기.
  • ID Verified: 호스트가 맞다고 확인(Proceed)해 줌.

2. Slot Map Status (슬롯 맵 상태)

ID가 확인되면 장비는 FOUP의 도어를 열고(Open Door), 내부에 25개의 슬롯 중 어디에 웨이퍼가 꽂혀 있는지 레이저 센서 등으로 매핑합니다.

  • Slot Map Not Read: 아직 문을 안 열었거나 매핑 전.
  • Waiting For Host: 매핑 결과를 호스트에 보고(S14F1 Event)하고 승인 대기. 호스트는 자신의 DB와 장비가 읽은 매핑 결과가 일치하는지 검증합니다.
  • Slot Map Verified: 매핑 일치 확인 완료. (이제 가공을 시작할 준비가 됨)

3. Access Status (접근 상태)

장비 로봇이 FOUP 내부의 웨이퍼를 꺼내거나 넣을 수 있는 상태인지를 나타냅니다. Not Accessed -> In Access -> Completed 순으로 진행됩니다.

3장. E87 핵심 메시지 및 제어 흐름

호스트와 장비는 E39(Object Services)를 활용하여 Carrier 객체를 제어합니다.

명령 (Action)설명
ProceedWithCarrierID나 Slot Map 확인 후, 다음 단계로 진행하라고 허가하는 호스트 명령.
CancelCarrier가짜 FOUP이거나 스케줄에 없는 FOUP일 경우 작업을 취소하고 내보내라는 명령.
CarrierOut가공이 끝났으니 FOUP을 장비에서 Unload(Clamp 해제) 하라는 명령.

4장. 실무 적용 및 트러블슈팅

Slot Map 불일치 처리 (Crossed Wafer / Double Wafer) 가장 흔한 에러입니다. 호스트는 1,2,3번 슬롯에 웨이퍼가 있다고 알고 있는데, 장비 센서가 1,2번에만 있거나 웨이퍼가 겹쳐서(Double) 꽂혀 있다고 읽는 경우입니다. 이 경우 호스트는 CancelCarrier를 지시하여 OHT로 FOUP을 빼내거나, 작업자가 수동 조치하도록 알람을 띄워야 합니다.
Access Mode 충돌 Load Port를 호스트가 제어할지(Auto), 작업자가 수동 조작할지(Manual)를 결정하는 Access Mode가 꼬이면 E87 상태 머신이 멈춥니다. 장비 UI에서 Manual로 FOUP을 넣었는데 호스트가 Auto 명령을 내리면 E87 위반 알람이 발생합니다.

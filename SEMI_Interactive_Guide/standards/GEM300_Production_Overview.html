4. 먼저 잡아야 할 관점

Carrier는 물류 단위

FOUP과 Load Port 상태가 안정되어야 이후 wafer 추적과 Job 실행이 흔들리지 않습니다.

Process Job은 공정 의도

어떤 재료를 어떤 recipe로 처리할지 정의합니다. 실행 자체는 Control Job과 함께 봐야 합니다.

Control Job은 실행 묶음

Carrier, wafer, Process Job을 실제 장비 실행 흐름으로 오케스트레이션합니다.

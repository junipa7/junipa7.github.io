01

Excel MES 전체 아키텍처 & 동작 원리

Excel VBA 기반 MES는 현장 작업자에게 가장 익숙한 엑셀 스프레드시트를 프론트엔드 UI로 활용하고, 백엔드는 엔터프라이즈 RDBMS인 MS-SQL Server를 결합하여 개발 생산성과 안정성을 극대화한 구조입니다.

시스템 3계층 (3-Tier) 구조도

1. Presentation Layer (UI)
Excel Workbook & Custom Ribbon

시트별 사용자 폼, 버튼(cmdDisplay, cmdSave), ActiveCell 변경 감지 이벤트

2. Business Logic Layer
VBA Class & Standard Modules

modADO, modSheet, MES_LotCreate, MES_Result 등 데이터 가공 및 프로시저 호출

3. Data Tier (DBMS)
MS-SQL Server [MESDB]

33개 테이블, 69개 저장 프로시저(SP), 트랜잭션 보장(ACID), 다단계 BOM CTE

💡 실무 원칙: VBA 코드 내에 인라인 SQL(SELECT * FROM ...)을 직접 작성하지 않고, 항상 dbo.InputPlan_Select, dbo.Lot_Process_Run과 같은 저장 프로시저(Stored Procedure)를 호출하여 보안과 실행계획 캐싱을 보장합니다.

[modADO.bas] MS-SQL ADODB 데이터베이스 연동 및 트랜잭션

modADO.bas는 모든 SQL 쿼리와 저장 프로시저를 실행하는 핵심 통신 라이브러리입니다.

1. DB 연결 및 자원 해제 패턴

modADO.bas - OpenConnection & CloseConnection 
Option Explicit

Private mConn As ADODB.Connection
Private mRS As ADODB.Recordset

' MS-SQL 데이터베이스에 ADODB로 연결 (IP, Port, 계정, 암호 지정)
Private Sub OpenConnection()
    Dim strConn As String, sServer As String
    
    sServer = MES_Master.Range("SERVER").Text
    If Trim(sServer) = "" Then sServer = "192.168.0.10"
    
    Set mConn = New ADODB.Connection
    strConn = "Provider=SQLOLEDB;Data Source=" & sServer & ",1433;" & _
              "Initial Catalog=MESDB;" & _
              "User ID=mes_admin;Password=mes_pwd_2026!;"
              
    mConn.Open strConn
End Sub

' Connection 및 Recordset 메모리 누수 방지 Close
Private Sub CloseConnection()
    If Not mRS Is Nothing Then
        If mRS.State = adStateOpen Then mRS.Close
        Set mRS = Nothing
    End If
    If Not mConn Is Nothing Then
        If mConn.State = adStateOpen Then mConn.Close
        Set mConn = Nothing
    End If
End Sub

2. CopyFromRecordset을 활용한 고속 Range 바인딩

modADO.bas - SelectToRange 
Public Function SelectToRange(ByRef sSQL As String, ByRef xRange As Range) As Boolean
    On Error GoTo ErrHandler
    SelectToRange = False
    
    Call OpenConnection
    Set mRS = New ADODB.Recordset
    mRS.Open sSQL, mConn, adOpenStatic, adLockReadOnly
    
    xRange.ClearContents
    If Not (mRS.EOF And mRS.BOF) Then
        xRange.Cells(1, 1).CopyFromRecordset mRS
        SelectToRange = True
    End If
    
    Call CloseConnection
    Exit Function
ErrHandler:
    Call CloseConnection
    MsgBox "조회 에러: " & Err.Description, vbCritical, "DB 오류"
End Function

Public Sub DeleteLine_Create(ByRef xTarget As Range)
    Dim c As Range
    For Each c In xTarget
        c.Font.Strikethrough = True
        c.Font.Color = RGB(150, 150, 150)
    Next c
End Sub

Public Sub DeleteLine_Cancel(ByRef xTarget As Range)

    Next c
End Sub

[MES_BillOfMaterial & frmMngTree] 다단계 BOM 트리뷰 제어

MS-SQL 재귀 CTE 쿼리 결과(Level, Parents, Child)를 읽어 엑셀 Treeview에 계층 트리 노드로 구성하는 알고리즘입니다.

modADO.bas - SelectToTreeview 
Public Sub SelectToTreeview(sSQL As String, xTreeView As TreeView)
    Dim xResult As Variant, iRow As Long
    Dim sKey As String, sParentKey As String, sText As String
    
    xResult = ExecCmd(sSQL)
    xTreeView.Nodes.Clear
    If IsArray(xResult) Then
        For iRow = 0 To UBound(xResult, 2)
            sKey = "K_" & xResult(0, iRow)
            sParentKey = "K_" & xResult(1, iRow)
            sText = xResult(2, iRow) & " [소요량: " & xResult(3, iRow) & "]"
            
            If xResult(1, iRow) = xResult(0, iRow) Or xResult(1, iRow) = "" Then
                xTreeView.Nodes.Add , , sKey, sText
            Else
                xTreeView.Nodes.Add sParentKey, tvwChild, sKey, sText
            End If
        Next iRow
    End If
End Sub

[MES_Inspection.cls] 품질 검사 측정치 입력 & 실시간 자동 판정

공정 스펙 기준에 따라 실측값을 입력받아 상한(USL)과 하한(LSL)을 비교하여 실시간 OK/NG를 판정합니다.

MES_Inspection.cls - Worksheet_Change Validation 
Private Sub Worksheet_Change(ByVal Target As Range)
    If Target.Column = 5 Then ' 실측치 컬럼
        Dim dVal As Double, dMin As Double, dMax As Double
        dVal = Val(Target.Value)
        dMin = Val(Cells(Target.Row, 3).Value)
        dMax = Val(Cells(Target.Row, 4).Value)
        
        If dVal >= dMin And dVal <= dMax Then
            Cells(Target.Row, 6).Value = "OK"
            Cells(Target.Row, 6).Font.Color = RGB(0, 150, 0)
        Else
            Cells(Target.Row, 6).Value = "NG"
            Cells(Target.Row, 6).Font.Color = RGB(220, 0, 0)
        End If
    End If
End Sub

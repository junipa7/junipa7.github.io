1. MES_LotStop.cls LOT 중지 및 해제 관리 상세 기술 분석서 화면 레이아웃 & UI 컨트롤 분석

MES_LotStop 화면은 자재 불량, 설비 이상, 품질 이상 등으로 인해 생산 라인의 특정 LOT를 즉시 중지(STOP)시키고, 원인 분석 및 대책 수립 후 다시 정상 작업(RUN)으로 복귀시키는 품질 보증 및 안전 통제 화면입니다.

구분엑셀 셀 주소명명된 범위 (Name)연계 DB 컬럼 / 컨트롤 설명
LOT 식별자 B1 Range("LOT_ID") 중지 대상 LOT 번호

중지 상세사유 H1 Range("STOP_REASON") 상세 사유 텍스트 (최소 5글자 이상 필수 입력)

2. MS-SQL Server 백엔드 구조 (MESDB_CREATE.sql)

MESDB_CREATE.sql에 정의된 백엔드 테이블 DDL 스키마 및 연계 저장 프로시저(Stored Procedure)의 완전한 T-SQL 구현 소스코드입니다.

TABLE [dbo].[LotStop] DDL Definition

LOT 중지 이력 테이블 DDL

CREATE TABLE [dbo].[LotStop](
    [Seq]         [bigint] IDENTITY(1,1) NOT NULL,
    [LotID]       [varchar](50) NOT NULL,
    [Process]     [smallint] NOT NULL,
    [StopCode]    [varchar](50) NOT NULL,
    [StopReason]  [varchar](500) NOT NULL,
    [StopUser]    [varchar](50) NOT NULL,
    [StopTime]    [datetime] NOT NULL,
    [ReleaseUser] [varchar](50) NULL,
    [ReleaseTime] [datetime] NULL,
    [Status]      [varchar](50) NOT NULL, -- STOP / RELEASE
    CONSTRAINT [PK_LotStop] PRIMARY KEY CLUSTERED ([Seq] ASC)
) ON [PRIMARY]
PROCEDURE [dbo].[LotStop_Stop] Stored Procedure

LOT 중지 트랜잭션

CREATE PROCEDURE [dbo].[LotStop_Stop](
    @LotID varchar(50),
    @Process smallint,
    @StopCode varchar(50),
    @StopReason varchar(500),
    @StopUser varchar(50)
)
AS
BEGIN
    SET NOCOUNT ON
    BEGIN TRANSACTION
    
    -- 1. 사유 길이 검증 (최소 5자)
    IF LEN(@StopReason) < 5
    BEGIN
        RAISERROR('중지 사유는 5자 이상 상세히 입력해야 합니다.', 16, -1)
        ROLLBACK TRANSACTION
        RETURN -10
    END

    -- 2. Lot 상태를 STOP으로 변경
    UPDATE dbo.Lot SET [Status] = 'STOP', EventTime = GETDATE(), EventUser = @StopUser WHERE LotID = @LotID

    -- 3. LotStop 이력 추가
    INSERT INTO dbo.LotStop (LotID, Process, StopCode, StopReason, StopUser, StopTime, [Status])
    VALUES (@LotID, @Process, @StopCode, @StopReason, @StopUser, GETDATE(), 'STOP')

    COMMIT TRANSACTION
    RETURN 0
END

4. MES_LotStop.cls 핵심 프로시저 상세 소스코드 해설

Private Sub cmdStop_Click() - 유효성 검사 및 중지 처리 Stop Controller

5자 이상 입력 제어 및 DB 중지 프로시저 호출

Private Sub cmdStop_Click()
    If Len(Trim(Range("STOP_REASON").Value)) < 5 Then
        MsgBox "중지 사유는 5글자 이상 입력해야 합니다.", vbExclamation, "입력 오류"
        Range("STOP_REASON").Select
        Exit Sub
    End If
    
    Dim sSQL As String
    sSQL = "dbo.LotStop_Stop '" & Range("LOT_ID").Value & "', " & _
           Range("PROCESS").Value & ", '" & _
           Range("STOP_CODE").Value & "', '" & _
           Range("STOP_REASON").Value & "', '" & _
           MES_Master.Range("WORKER").Text & "'"
    Call ExecCmd(sSQL)
    MsgBox "LOT가 중지 처리되었습니다.", vbInformation, "완료"
End Sub
💡 핵심 로직 및 현장 적용 포인트:
  • 사유가 5글자 미만인 경우 클라이언트 단에서 즉시 차단하여 데이터 정합성을 보호합니다.

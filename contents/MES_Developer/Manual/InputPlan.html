1. MES_InputPlan.cls 생산 투입 계획 수립 상세 기술 분석서 화면 레이아웃 & UI 컨트롤 분석

MES_InputPlan 화면은 생산 관리자가 특정 기간(From ~ To Date) 동안 특정 기종을 얼마만큼 생산할 것인지 투입 계획(PlanID)을 등록하고 관리하는 화면입니다. 행을 추가하면 기본 1000EA 수량이 자동으로 세팅되며, 계획 행을 더블클릭하면 즉시 LOT 생성 화면(MES_LotCreate)으로 전환되어 해당 계획에 대한 작업 지시 LOT를 발행할 수 있습니다.

구분엑셀 셀 주소명명된 범위 (Name)연계 DB 컬럼 / 컨트롤 설명
조회 시작일 B1 Range("FROM_DATE") 계획 조회 시작일 (yyyy-mm-dd)
조회 종료일 D1 Range("TO_DATE") 계획 조회 종료일 (yyyy-mm-dd)
기종 필터 F1 Range("MANAGEMENT") 기종 필터 드롭다운 (전체 또는 특정 기종)
ActiveX 버튼 상단 행 cmdDisplay, cmdDelete, cmdSave [조회], [삭제] 취소선, [저장] 일괄 트랜잭션
데이터 영역 A3:G25 Range("DATA") 투입 계획 데이터 그리드
컬럼 1 (A열) DATA.Columns(1) - dbo.InputPlan.PlanID (계획고유번호 - varchar(50), PK)
컬럼 2 (B열) DATA.Columns(2) - dbo.InputPlan.Management (기종코드 - varchar(50))
컬럼 3 (C열) DATA.Columns(3) - dbo.InputPlan.PlanCount (계획 수량 - int, 기본 1000)
컬럼 4 (D열) DATA.Columns(4) - dbo.InputPlan.Status (진행상태 - PLAN/RUN/END)
컬럼 5 (E열) DATA.Columns(5) - dbo.InputPlan.EventTime (등록일시)
컬럼 6 (F열) DATA.Columns(6) - dbo.InputPlan.EventUser (등록자)

2. MS-SQL Server 백엔드 구조 (MESDB_CREATE.sql)

MESDB_CREATE.sql에 정의된 백엔드 테이블 DDL 스키마 및 연계 저장 프로시저(Stored Procedure)의 완전한 T-SQL 구현 소스코드입니다.

TABLE [dbo].[InputPlan] DDL Definition

생산 투입 계획 테이블 DDL

CREATE TABLE [dbo].[InputPlan](
    [PlanID]     [varchar](50) NOT NULL, -- 생산 계획 고유번호 (PK)
    [Management] [varchar](50) NOT NULL, -- 기종코드
    [PlanCount]  [int] NOT NULL,         -- 계획 수량
    [Status]     [varchar](50) NOT NULL, -- 상태 (PLAN: 계획수립, RUN: 생산중, END: 완료)
    [EventTime]  [datetime] NOT NULL,    -- 등록일시
    [EventUser]  [varchar](50) NOT NULL, -- 등록자
    CONSTRAINT [PK_InputPlan] PRIMARY KEY CLUSTERED ([PlanID] ASC)
) ON [PRIMARY]
PROCEDURE [dbo].[InputPlan_Select] Stored Procedure

기간 및 기종별 투입 계획 조회

CREATE PROCEDURE [dbo].[InputPlan_Select](
    @FromDate varchar(10),
    @ToDate varchar(10),
    @Management varchar(50)
)
AS
BEGIN
    SET NOCOUNT ON
    SELECT * FROM dbo.InputPlan WITH(NOLOCK)
    WHERE EventTime >= @FromDate AND EventTime <= DATEADD(DAY, 1, @ToDate)
      AND (@Management = '전체' OR Management = @Management)
    ORDER BY EventTime DESC
    RETURN 0
END
PROCEDURE [dbo].[InputPlan_Save] Stored Procedure (UPSERT)

투입 계획 저장 및 신규 PlanID 자동 채번

CREATE PROCEDURE [dbo].[InputPlan_Save](
    @PlanID varchar(50),
    @Management varchar(50),
    @PlanCount int,
    @Status varchar(50),
    @EventTime datetime,
    @EventUser varchar(50) = 'SYSTEM'
)
AS
BEGIN
    SET NOCOUNT ON
    DECLARE @CurrentTime datetime
    SET @CurrentTime = GETDATE()

    -- 1. 기종코드 검증
    IF NOT EXISTS (SELECT 1 FROM dbo.Management WHERE Management = @Management)
    BEGIN
        RAISERROR('dbo.InputPlan_Save : Management 코드 오류 [%s]', 16, -1, @Management)
        RETURN -10
    END

    -- 2. 신규 등록 시 PlanID 자동 채번 (예: PLN-YYYYMMDD-001)
    IF @PlanID = '' OR @PlanID IS NULL
    BEGIN
        DECLARE @Seq int
        SELECT @Seq = ISNULL(MAX(CAST(RIGHT(PlanID, 3) AS int)), 0) + 1 
        FROM dbo.InputPlan 
        WHERE PlanID LIKE 'PLN-' + CONVERT(varchar(8), GETDATE(), 112) + '%'
        
        SET @PlanID = 'PLN-' + CONVERT(varchar(8), GETDATE(), 112) + '-' + RIGHT('000' + CAST(@Seq AS varchar(3)), 3)
    END

    -- 3. UPSERT 실행
    IF (SELECT COUNT(*) FROM dbo.InputPlan WHERE PlanID = @PlanID) = 0
        INSERT INTO dbo.InputPlan VALUES(@PlanID, @Management, @PlanCount, ISNULL(@Status, 'PLAN'), @CurrentTime, @EventUser);
    ELSE
        UPDATE dbo.InputPlan
        SET Management = @Management,
            PlanCount = @PlanCount,
            [Status] = @Status,
            EventTime = @CurrentTime,
            EventUser = @EventUser
        WHERE PlanID = @PlanID

    RETURN 0
END

4. MES_InputPlan.cls 핵심 프로시저 상세 소스코드 해설

AutoChangeValue(iRownumber) - 기본 수량 및 상태 자동 설정 Auto Value

신규 계획 등록 시 수량 1000EA 및 상태 PLAN 자동 세팅

Private Sub AutoChangeValue(iRownumber As Long)
    '3열(계획수량)이 비어있으면 1000EA 기본값 부여
    If Range("DATA").Cells(iRownumber, 3).Value = "" Then
        Range("DATA").Cells(iRownumber, 3).Value = 1000
    End If
    
    '4열(상태)이 비어있으면 'PLAN' 부여
    If Range("DATA").Cells(iRownumber, 4).Value = "" Then
        Range("DATA").Cells(iRownumber, 4).Value = "PLAN"
    End If
    
    '등록일시 및 작업자
    Range("DATA").Cells(iRownumber, 5).Value = DateTime.Now()
    Range("DATA").Cells(iRownumber, 6).Value = MES_Master.Range("WORKER").Text
End Sub
💡 핵심 로직 및 현장 적용 포인트:
  • 관리자가 기종만 선택하면 표준 로트 기본 수량(1,000개)과 초기 상태(PLAN)가 자동으로 채워집니다.

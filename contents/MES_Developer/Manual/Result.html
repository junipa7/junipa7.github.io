MES_Result.cls 공정 생산실적 및 불량 등록 상세 기술 분석서

LOT별 공정 착공(RUN) 및 완료 실적 저장, 작업자/설비 배정, 검사 인터락 및 불량 항목 다중 직렬화(RangeToString) 저장

화면 모듈
MES_Result.cls
매핑 백엔드 테이블
dbo.ProcessResult, dbo.BadResult
연계 저장 프로시저
ProcessResult_Save / BadResult_Save / Lot_Process_Run
불량 직렬화 저장
modSheet.RangeToString 연동

1. MES_Result.cls 공정 생산실적 및 불량 등록 상세 기술 분석서 화면 레이아웃 & UI 컨트롤 분석

MES_Result 화면은 현장 작업자가 LOT의 각 공정 착공(Run)과 완료 실적(양품 수량, 불량 수량, 투입 설비, 작업자)을 등록하는 MES 시스템의 핵심 생산 실행 인터페이스입니다. 하단 불량 그리드(DEFECT_DATA)에 입력된 다수의 불량 항목을 단 1회 트랜잭션으로 직렬화하여 백엔드에 안전하게 저장합니다.

▲ [MES_Result.jpg] 실제 엑셀 클라이언트 구동 화면 (상단 조회조건/ActiveX 버튼 및 DATA 그리드)
구분엑셀 셀 주소명명된 범위 (Name)연계 DB 컬럼 / 컨트롤 설명
LOT 식별자 B1 Range("LOT_ID") 작업 대상 LOT 번호 (바코드 스캔 또는 화면 링크)
진행 공정 D1 Range("PROCESS") 현재 진행 공정코드
작업 설비 F1 Range("MACHINE") 투입 생산 설비코드
작업자 H1 Range("WORKER") 작업자 사번/이름
수량 정보 B3, D3, F3 투입/양품/불량수량 투입수량(InputCount), 양품수량(ResultCount), 불량수량(BadCount)
불량 상세 영역 A7:D15 Range("DEFECT_DATA") 불량코드(BadCode), 불량명, 불량수량 입력 그리드
ActiveX 버튼 상단 행 cmdRun, cmdSave, cmdInspection [공정착공], [실적저장], [검사화면 이동] 버튼

2. MS-SQL Server 백엔드 구조 (MESDB_CREATE.sql)

MESDB_CREATE.sql에 정의된 백엔드 테이블 DDL 스키마 및 연계 저장 프로시저(Stored Procedure)의 완전한 T-SQL 구현 소스코드입니다.

TABLE [dbo].[ProcessResult] DDL Definition

공정 실적 테이블 DDL

CREATE TABLE [dbo].[ProcessResult](
    [LotID]       [varchar](50) NOT NULL, -- LOT 번호
    [Process]     [smallint] NOT NULL,    -- 공정코드
    [InputCount]  [int] NOT NULL,         -- 투입 수량
    [ResultCount] [int] NOT NULL,         -- 양품 완료 수량
    [BadCount]    [int] NOT NULL,         -- 불량 수량
    [Status]      [varchar](50) NOT NULL, -- 공정상태 (RUN, END)
    [Machine]     [varchar](50) NULL,     -- 작업 설비
    [Worker]      [varchar](50) NOT NULL, -- 작업자
    [StartTime]   [datetime] NOT NULL,    -- 착공 일시
    [EndTime]     [datetime] NULL,        -- 완료 일시
    [EventTime]   [datetime] NOT NULL,    -- 등록 일시
    [EventUser]   [varchar](50) NOT NULL, -- 등록자
    CONSTRAINT [PK_ProcessResult] PRIMARY KEY CLUSTERED ([LotID] ASC, [Process] ASC)
) ON [PRIMARY]
PROCEDURE [dbo].[ProcessResult_Save] Stored Procedure

공정 실적 완료 트랜잭션

CREATE PROCEDURE [dbo].[ProcessResult_Save](
    @LotID varchar(50),
    @Process smallint,
    @InputCount int,
    @ResultCount int,
    @BadCount int,
    @Machine varchar(50),
    @Worker varchar(50),
    @BadDataList varchar(MAX) = '' -- 직렬화된 불량 목록 문자열
)
AS
BEGIN
    SET NOCOUNT ON
    BEGIN TRANSACTION
    
    -- 1. 투입수량 = 양품수량 + 불량수량 일치 검증
    IF @InputCount <> (@ResultCount + @BadCount)
    BEGIN
        RAISERROR('투입 수량과 양품+불량 합계가 일치하지 않습니다.', 16, -1)
        ROLLBACK TRANSACTION
        RETURN -10
    END

    -- 2. ProcessResult 갱신
    UPDATE dbo.ProcessResult
    SET ResultCount = @ResultCount,
        BadCount = @BadCount,
        [Status] = 'END',
        Machine = @Machine,
        Worker = @Worker,
        EndTime = GETDATE(),
        EventTime = GETDATE(),
        EventUser = @Worker
    WHERE LotID = @LotID AND Process = @Process

    -- 3. 불량 데이터(BadResult) 다중 저장 (String Parsing)
    IF @BadDataList <> ''
    BEGIN
        -- BadResult_Save를 내부적으로 호출하여 불량 상세 적재
        EXEC dbo.BadResult_BatchSave @LotID, @Process, @BadDataList, @Worker
    END

    COMMIT TRANSACTION
    RETURN 0
END

3. VBA 클라이언트 동작 라이프사이클 & 상태 관리

1. LOT 조회 & 착공
cmdRun_Click
LOT 바코드 스캔 후 dbo.Lot_Process_Run 호출하여 공정 시작시간(StartTime) 기록
2. 검사 연계 (필요시)
cmdInspection_Click
해당 공정이 검사공정인 경우 MES_Inspection 화면으로 전환하여 측정값 입력
3. 불량 입력
Range('DEFECT_DATA')
발생한 불량 항목과 수량을 그리드에 입력 (수량 합계 자동 계산)
4. 실적 일괄 저장
cmdSave_Click
RangeToString으로 불량 데이터를 직렬화하고 ProcessResult_Save 호출 완료

4. MES_Result.cls 핵심 프로시저 상세 소스코드 해설

Private Sub cmdSave_Click() - 실적 및 불량 직렬화 저장 Result Saver

실적 데이터 및 다중 불량 레코드를 일괄 트랜잭션 저장

Private Sub cmdSave_Click()
    Dim sSQL As String
    Dim sDefectString As String
    
    '불량 그리드의 데이터를 문자열로 직렬화 (modSheet.RangeToString 활용)
    sDefectString = RangeToString(Range("DEFECT_DATA"))
    
    sSQL = "dbo.ProcessResult_Save '" & Range("LOT_ID").Value & "', " & _
           Range("PROCESS").Value & ", " & _
           Range("INPUT_COUNT").Value & ", " & _
           Range("RESULT_COUNT").Value & ", " & _
           Range("BAD_COUNT").Value & ", '" & _
           Range("MACHINE").Value & "', '" & _
           Range("WORKER").Value & "', '" & sDefectString & "'"
           
    Call ExecCmd(sSQL)
    MsgBox "공정 실적이 성공적으로 저장되었습니다.", vbInformation, "완료"
End Sub
💡 핵심 로직 및 현장 적용 포인트:
  • RangeToString을 통해 수십 개의 불량 행을 단 1회의 네트워크 패킷으로 백엔드 SP에 전달하여 초고속 저장을 실현합니다.

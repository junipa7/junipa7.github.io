📚 엑셀 VBA 심화 학습 & 추천 참조 자료

스마트 MES 시스템 개발, 유지보수 및 고성능 VBA 프로그래밍을 위한 핵심 추천 문서와 기술 가이드 모음

📖 Deep Inside VBA (WikiDocs) ↗ 온라인 도서 / 원리 해설

VBA의 단순 문법을 넘어, 내부 런타임 엔진 동작 원리, 메모리 할당 구조, 문자열 포인터(BSTR/StrPtr), SAFEARRAY 배열 구조, COM 객체 바이딩을 심도 있게 다루는 국내 최고의 VBA 심화 기술 도서입니다.

💡 스마트 MES 적용 연계 포인트:
  • modADO.ExecCmd 및 GetRows를 통한 2차원 SAFEARRAY 메모리 직접 바인딩 원리 이해
  • modUpgrade의 런타임 핫패치(VBAProject 내부 조작) 메커니즘 심화 학습
  • 대용량 데이터 처리 시 불필요한 메모리 복사를 방지하는 가변인자 및 ByRef 전달 최적화
📘 [VBA] Workbook 완벽 가이드 (Kukuta's Blog) ↗ 통합문서 객체 제어

Workbook 객체의 생명주기(Open, BeforeSave, BeforeClose 이벤트), Workbooks.Add/Open/SaveCopyAs 메서드, 보안/보호 속성 및 다중 통합문서 간 데이터 동기화 기법을 완벽히 정리한 가이드입니다.

💡 스마트 MES 적용 연계 포인트:
  • modADO.UpgradeFileSave의 ThisWorkbook.SaveCopyAs 임시 파일 생성 및 DB 업로드 로직 이해
  • modExt.DeleteVBA에서 다중 워크북(Workbooks(2)) 참조 및 배포용 클린 워크북 변환 기법 적용
📗 [VBA] Worksheet 완벽 가이드 (Kukuta's Blog) ↗ 워크시트 객체 모델

Worksheet 객체의 핵심 속성, 시트 이벤트(Worksheet_Activate, Worksheet_Change, Worksheet_SelectionChange), 그리고 시트 동적 생성/삭제/보호 기법을 체계적으로 다룹니다.

💡 스마트 MES 적용 연계 포인트:
  • 모든 화면 클래스(MES_Process, MES_Result 등)의 Worksheet_Activate 시 초기화 패턴
  • Worksheet_Change 이벤트에서 Application.ScreenUpdating = False를 통한 무한 루프(Event Cascading) 차단
  • modExt.Create_MES_Product_Process의 Worksheets.Add 시트 자동 생성 및 ActiveX 컨트롤 배치
📙 [Excel/VBA] 셀과 범위 선택하기 총정리! (KnowHowBank) ↗ 셀/영역 탐색 테크닉

Select를 배제하고 속도를 극대화하는 Range 탐색 방법, Offset, Resize, End(xlDown/xlUp), CurrentRegion, UsedRange 활용법을 실무 중심으로 정리한 글입니다.

💡 스마트 MES 적용 연계 포인트:
  • modSheet.LineRange의 Target.CurrentRegion.Offset 및 Resize를 통한 1개 행 동적 선택
  • modSheet.FindNullRow의 Target.End(xlDown).Row + 1 빈 행 탐색 알고리즘
📕 엑셀 VBA(16): Range 총정리 (네이버 블로그) ↗ Range 핵심 속성 예제

실무 엑셀 개발에서 필수적인 Range 객체의 폰트 서식, 배경색(Interior), 테두리(Borders), 값(Value/Text), 수식(FormulaR1C1) 및 주소(Address) 제어 예제를 직관적으로 설명합니다.

💡 스마트 MES 적용 연계 포인트:
  • modSheet.DeleteLine_Create / Cancel의 Font.Strikethrough = True 취소선 처리
  • modExt.Create_MES_Product_Process의 표준 색상(Color = 65535), 테두리(Weight = xlThin) 자동 서식화
📓 [VBA] Range와 Cell 완벽 가이드 (Kukuta's Blog) ↗ 성능 최적화 & 배열 매핑

Range("A1")와 Cells(row, col)의 차이점, 루프 연산 시 셀 직접 접근 대신 2차원 Variant 배열로 메모리에 한 번에 올리고 내리는 초고속 성능 튜닝 기법을 설명합니다.

💡 스마트 MES 적용 연계 포인트:
  • Range("DATA").Rows.Count 루프와 Cells(iDataRow, col) 매핑 구조
  • modSheet.RangeToString을 이용한 다중 Range 셀 값의 고속 직렬화(Serialization)
  • CopyFromRecordset을 이용한 셀 단위 반복문 없는 단 1줄 고속 데이터 출력

1. MES_Master.cls 메인 마스터 & 런타임 핫패치 상세 기술 분석서 화면 레이아웃 & UI 컨트롤 분석

MES_Master 화면은 작업자 로그인 인증을 수행하고 시스템 전역에 작업자 사번(WORKER)을 공유하는 메인 홈 화면이자, 관리자가 각 모듈의 버전 이력을 확인하고 SQL 쿼리/프로시저 코드를 엑셀 화면에서 직접 수정하여 서버에 실시간 무중단 배포(Hot-Patch)하는 관리자 포털 화면입니다.

데이터 영역 A5:G25 Range("DATA") 모듈별 버전 및 SQL 소스코드 그리드

2. MS-SQL Server 백엔드 구조 (MESDB_CREATE.sql)

MESDB_CREATE.sql에 정의된 백엔드 테이블 DDL 스키마 및 연계 저장 프로시저(Stored Procedure)의 완전한 T-SQL 구현 소스코드입니다.

TABLE [dbo].[UpgradeMaster] DDL Definition

모듈 버전 및 쿼리 핫패치 테이블 DDL

CREATE TABLE [dbo].[UpgradeMaster](
    [Seq]        [int] IDENTITY(1,1) NOT NULL,
    [Module]     [varchar](50) NOT NULL, -- 모듈명 (MES_Process 등)
    [Version]    [int] NOT NULL,         -- 버전 번호
    [QueryName]  [varchar](50) NOT NULL, -- 저장 프로시저명
    [QueryCode]  [varchar](MAX) NULL,    -- T-SQL 쿼리 소스코드
    [EventTime]  [datetime] NOT NULL,    -- 배포 일시
    [EventUser]  [varchar](50) NOT NULL, -- 배포 관리자
    CONSTRAINT [PK_UpgradeMaster] PRIMARY KEY CLUSTERED ([Seq] ASC)
) ON [PRIMARY]
PROCEDURE [dbo].[MESUserCheck] Stored Procedure

작업자 인증 프로시저

CREATE PROCEDURE [dbo].[MESUserCheck](
    @Worker varchar(50),
    @Password varchar(50)
)
AS
BEGIN
    SET NOCOUNT ON
    IF EXISTS (SELECT 1 FROM dbo.[User] WHERE Worker = @Worker AND [Password] = @Password AND [Status] = 'ACTIVE')
        SELECT 1 AS AuthResult, [Name], [Role] FROM dbo.[User] WHERE Worker = @Worker
    ELSE
        SELECT 0 AS AuthResult, '' AS [Name], '' AS [Role]
    RETURN 0
END

4. MES_Master.cls 핵심 프로시저 상세 소스코드 해설

Private Sub cmdSave_Click() - 런타임 핫패치 배포 Hot-Patch Deployer

SQL 쿼리 런타임 무중단 배포 서브루틴

Private Sub cmdSave_Click()
    Dim i As Long, sSQL As String
    For i = 1 To Range("DATA").Rows.Count
        If Range("DATA").Cells(i, 1).Value = "" Then Exit For
        '수정된 쿼리 소스코드를 UpgradeMaster 테이블에 버전업 저장
        sSQL = "dbo.UpgradeMaster_Save '" & _
               Range("DATA").Cells(i, 1).Value & "', '" & _
               Range("DATA").Cells(i, 3).Value & "', '" & _
               Replace(Range("DATA").Cells(i, 4).Value, "'", "''") & "', '" & _
               Range("WORKER").Value & "'"
        Call ExecCmd(sSQL)
    Next
    MsgBox "모듈 쿼리 핫패치가 성공적으로 배포되었습니다.", vbInformation, "완료"
End Sub
💡 핵심 로직 및 현장 적용 포인트:
  • 클라이언트 프로그램을 재배포하거나 엑셀을 다시 켤 필요 없이, 서버 DB에 즉시 신규 로직이 반영되는 무중단 핫패칭 기술입니다.

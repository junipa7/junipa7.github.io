1. MES_LotCreate.cls LOT 생성 및 발행 상세 기술 분석서 화면 레이아웃 & UI 컨트롤 분석

MES_LotCreate 화면은 승인된 생산 투입 계획(PlanID)을 바탕으로 현장에서 실물 제품을 추적할 고유한 LOT 식별 번호(LotID)를 자동 채번하고 발행하는 핵심 생산 시작 인터페이스입니다. 발행된 LOT 번호를 더블클릭하면 즉시 공정 실적 등록 화면(MES_Result)으로 라우팅됩니다.

컬럼 2 (B열) DATA.Columns(2) - dbo.Lot.PlanID (연계 계획번호 - varchar(50))

컬럼 4 (D열) DATA.Columns(4) - dbo.Lot.Count (LOT 수량 - int)
컬럼 5 (E열) DATA.Columns(5) - dbo.Lot.Status (LOT 상태 - CREATE / RUN / STOP / END)
컬럼 6 (F열) DATA.Columns(6) - dbo.Lot.EventTime (발행일시)
컬럼 7 (G열) DATA.Columns(7) - dbo.Lot.EventUser (발행자)

2. MS-SQL Server 백엔드 구조 (MESDB_CREATE.sql)

MESDB_CREATE.sql에 정의된 백엔드 테이블 DDL 스키마 및 연계 저장 프로시저(Stored Procedure)의 완전한 T-SQL 구현 소스코드입니다.

TABLE [dbo].[Lot] DDL Definition

생산 LOT 마스터 테이블 DDL

CREATE TABLE [dbo].[Lot](
    [LotID]      [varchar](50) NOT NULL, -- LOT 고유 식별자 (PK)
    [PlanID]     [varchar](50) NOT NULL, -- 생산 계획번호 (FK)
    [Management] [varchar](50) NOT NULL, -- 기종코드 (FK)
    [Count]      [int] NOT NULL,         -- LOT 단위 수량
    [Status]     [varchar](50) NOT NULL, -- LOT 상태 (CREATE/RUN/STOP/END)
    [EventTime]  [datetime] NOT NULL,    -- 발행일시
    [EventUser]  [varchar](50) NOT NULL, -- 발행자
    CONSTRAINT [PK_Lot] PRIMARY KEY CLUSTERED ([LotID] ASC)
) ON [PRIMARY]
PROCEDURE [dbo].[Lot_Create] Stored Procedure

고유 LOT 번호 자동 채번 및 발행

CREATE PROCEDURE [dbo].[Lot_Create](
    @PlanID varchar(50),
    @Management varchar(50),
    @Count int,
    @EventUser varchar(50) = 'SYSTEM'
)
AS
BEGIN
    SET NOCOUNT ON
    DECLARE @LotID varchar(50)
    DECLARE @Seq int
    DECLARE @Today varchar(8)
    SET @Today = CONVERT(varchar(8), GETDATE(), 112)

    -- 당일 시퀀스 채번 (예: LOT-20260826-0001)
    SELECT @Seq = ISNULL(MAX(CAST(RIGHT(LotID, 4) AS int)), 0) + 1
    FROM dbo.Lot WITH(UPDLOCK)
    WHERE LotID LIKE 'LOT-' + @Today + '%'

    SET @LotID = 'LOT-' + @Today + '-' + RIGHT('0000' + CAST(@Seq AS varchar(4)), 4)

    -- 신규 LOT INSERT
    INSERT INTO dbo.Lot (LotID, PlanID, Management, [Count], [Status], EventTime, EventUser)
    VALUES (@LotID, @PlanID, @Management, @Count, 'CREATE', GETDATE(), @EventUser)

    -- 결과 반환
    SELECT * FROM dbo.Lot WHERE LotID = @LotID
    RETURN 0
END

4. MES_LotCreate.cls 핵심 프로시저 상세 소스코드 해설

Private Sub cmdLotCreate_Click() - LOT 발행 LOT Creator

계획 기반 LOT 발행 트리거 서브루틴

Private Sub cmdLotCreate_Click()
    Dim sSQL As String
    If Range("PLAN_ID").Value = "" Or Range("MANAGEMENT").Value = "" Then
        MsgBox "계획번호와 기종코드를 확인하세요.", vbExclamation, "경고"
        Exit Sub
    End If
    
    'Lot_Create 저장 프로시저 호출
    sSQL = "dbo.Lot_Create '" & Range("PLAN_ID").Value & "', '" & Range("MANAGEMENT").Value & "', 1000, '" & MES_Master.Range("WORKER").Text & "'"
    Call ExecCmd(sSQL)
    
    '화면 재조회
    Call cmdDisplay_Click
End Sub

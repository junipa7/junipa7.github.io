1. 모듈 개요 및 전역 객체 구조

modADO 모듈은 Excel VBA 클라이언트와 MS-SQL Server 간의 고성능 데이터 세션 통신, 쿼리 실행, 자동 시트 바인딩, 계층형 BOM 전개, WMI 단말 보안 및 프로그램 바이너리 스트림 기반의 버전 자동 배포(OTA Auto-Upgrade) 기능을 전담하는 핵심 통신 모듈입니다.

2. DB 연결 및 세션 생명주기 관리

Private Sub OpenConnection() Private

엑셀 시트 내 Range("SERVER") 셀 값에 따라 운영 서버, 원격 테스트 서버, 로컬 Express DB로 분기 접속합니다.

Private Sub OpenConnection()
    Dim sConnString As String
    
    If Range("SERVER").text = "운영서버" Then
        sConnString = "Driver={SQL Server};Server=203.249.29.116,1433;Database=MESDB;Uid=sa1;pwd=qwer1234!;Connect Timeout=60;"
    ElseIf Range("SERVER").text = "Huni Home" Then
        sConnString = "Driver={SQL Server};Server=leesh.iptime.org,1214;Database=TESTDB;Uid=mesuser;pwd=hunihome1004;Connect Timeout=60;"
    Else
        sConnString = "Driver={SQL Server};Server=localhost\SQLEXPRESS;Database=MESDB;Uid=mesuser;pwd=mesuser1;Connect Timeout=60;"
    End If
    
    mDataBase.ConnectionString = sConnString
    Call mDataBase.Open
    mCmd.ActiveConnection = mDataBase
End Sub
💡 기술 분석:
  • 환경 동적 스위칭: 워크시트 설정값만으로 개발/테스트/운영 환경을 즉시 전환합니다.
  • 타임아웃 제어: Connect Timeout=60 설정을 통해 공장 네트워크 불안정 시 과도한 블로킹을 방지합니다.
Private Function ExecuteCmd(sSQL As String) As Boolean Private

SQL 쿼리 또는 저장 프로시저를 실행하고, 에러 발생 시 OLEDB 헤더를 제거한 후 사용자 친화적인 메시지를 표시합니다.

Private Function ExecuteCmd(sSQL As String) As Boolean
    On Error GoTo ErrorHandler
    
    mCmd.CommandText = sSQL
    Set mRS = mCmd.Execute
    ExecuteCmd = True
    Exit Function
    
ErrorHandler:
    ExecuteCmd = False
    If Err <> 0 Then
        ' OLEDB/ODBC의 기본 오류 헤더(47자)를 잘라내고 핵심 SQL Server 에러 메시지만 출력
        MsgBox "[SQL Server오류]" & Mid(Err.Description, 48, 999), , "Error"
    End If
End Function

3. 고속 데이터 추출 및 엑셀 바인딩 함수군

Public Function ExecCmd(sSQL As String) As Variant Public

조회 결과를 메모리 내 2차원 Variant 배열(GetRows)로 즉시 덤프하여 반환합니다.

Public Function ExecCmd(ByVal sSQL As String) As Variant
    Call OpenConnection
    If Not ExecuteCmd(sSQL) Then
        Call CloseConnection
        Exit Function
    End If

    If mRS.State > 0 Then
        If mRS.BOF = False Or mRS.EOF = False Then
            ExecCmd = mRS.GetRows
        End If
    End If
    Call CloseConnection
End Function
Public Function SelectToSheet(sSQL, xRange, [iSkipClear]) As Boolean Public

CopyFromRecordset을 통해 대량 데이터를 시트에 초고속으로 출력하며, NextRecordset을 이용해 다중 결과셋(Multiple Areas) 매핑을 지원합니다.

Public Function SelectToSheet(ByRef sSQL As String, ByRef xRange As Range, Optional iSkipClear As Integer = 0) As Boolean
    On Error GoTo ErrorHandler
    Dim iCount As Integer

    Call OpenConnection
    If Not ExecuteCmd(sSQL) Then
        Call CloseConnection
        SelectToSheet = False
        Exit Function
    End If
    SelectToSheet = True

    Application.ScreenUpdating = False
    For iCount = 1 To xRange.Areas.Count
        xRange.Areas.Item(iCount).CurrentRegion.Offset(1, iSkipClear).ClearContents
        xRange.Areas.Item(iCount).Offset(0, iSkipClear).CopyFromRecordset mRS
        
        If mRS.BOF = True And mRS.EOF = True Then
            SelectToSheet = False
        End If
        Set mRS = mRS.NextRecordset
    Next
  
    Call CloseConnection
    Application.ScreenUpdating = True
    Exit Function
ErrorHandler:
    Call CloseConnection
    If Err <> 0 Then MsgBox "[SQL Server오류]" & Mid(Err.Description, 48, 999), , "Error"
End Function

단일 기준정보 또는 코드값을 조회하는 공통 저장 프로시저 One_Select를 호출하여 첫 번째 컬럼 값을 반환합니다.

4. 자재 구조(BOM) 트리 전개 및 단말 보안

Public Sub SelectToTreeview(sSQL As String, xTreeView As TreeView) Public

완제품(FERT)은 루트 노드로, 하위 자재는 부모 키(Parents)를 참조하여 MSComctlLib TreeView 컨트롤에 재귀적 계층 노드를 생성합니다.

xTreeView.Nodes.Clear
Do Until mRS.EOF
    sNodetext = mRS!Type.value & " > " & mRS!Material.value & " : " & mRS!Name.value & " * " & mRS!Qty.value & " EA"
    If mRS!Type = "FERT" Then
        Set xNode = xTreeView.Nodes.Add(, , Key:=mRS!Material.value, text:=sNodetext)
    Else
        Set xNode = xTreeView.Nodes.Add(mRS!Parents.value, tvwChild, mRS!Material.value, sNodetext)
    End If
    xNode.Expanded = True
    mRS.MoveNext
Loop

5. 바이너리 스트림 기반 클라이언트 자동 배포 (OTA)

Public Sub UpgradeFileSave() / UpgradeFileLoad(sFilename) Public

ADODB.Stream 객체를 활용하여 실행 중인 .xlsm 바이너리를 DB의 dbo.UpgradeFiles 테이블에 BLOB 형태로 버전업 저장하고 다운로드합니다.

' 배포 저장
ThisWorkbook.SaveCopyAs ("__MES_Save_Copy_File__.xlsm")
xStream.Type = adTypeBinary
xStream.Open
xStream.LoadFromFile "__MES_Save_Copy_File__.xlsm"
mRS.Fields("FileNAme").value = sFilename
mRS.Fields("Version").value = mRS.Fields("Version").value + 1
mRS.Fields("Data").value = xStream.Read
mRS.Fields("EventTime").value = DateTime.Now()
mRS.Fields("EventUser").value = MES_Master.Range("WORKER")
mRS.Update

' 배포 다운로드
xStream.Write mRS!Data
xStream.SaveToFile sFilename
🌟 현장 적용 강점: 작업장 수십 대의 PC를 직접 방문할 필요 없이, 서버 DB에 업로드된 최신 엑셀 MES 클라이언트를 자동으로 배포·동기화할 수 있는 강력한 배포 체계입니다.

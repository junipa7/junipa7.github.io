1. MES_Management.cls 기종 마스터 관리 상세 기술 분석서 화면 레이아웃 & UI 컨트롤 분석

MES_Management 화면은 공장에서 생산되는 모든 제품 기종 코드와 기종명, 제품유형(완제품, 반제품, 원자재 등), 표준 공수(TactTime)를 등록하고 관리하는 기준정보의 중심 화면입니다. 특정 기종 셀을 더블클릭하면 해당 기종의 공정 사양(MngSpec) 또는 자재명세서(BillOfMaterial) 화면으로 즉시 전환됩니다.

구분엑셀 셀 주소명명된 범위 (Name)연계 DB 컬럼 / 컨트롤 설명
조회 조건 B1 Range("TYPE") 제품유형 필터 (드롭다운: '전체,완제품,반제품,원자재')
ActiveX 버튼 상단 행 cmdDisplay, cmdDelete, cmdSave [조회] 쿼리 실행, [삭제] 빨간색 취소선 설정, [저장] 일괄 UPSERT 트랜잭션
데이터 영역 A3:G25 Range("DATA") 기종 마스터 레코드 그리드
컬럼 1 (A열) DATA.Columns(1) - dbo.Management.Management (기종코드 - varchar(50), PK)
컬럼 2 (B열) DATA.Columns(2) - dbo.Management.Name (기종명 - varchar(50))
컬럼 3 (C열) DATA.Columns(3) - dbo.Management.Type (제품유형 - 공통코드 'Management.Type' 드롭다운)
컬럼 4 (D열) DATA.Columns(4) - dbo.Management.TactTime (표준 택트타임/초 - int)
컬럼 5 (E열) DATA.Columns(5) - dbo.Management.EventTime (등록일시 - DateTime.Now())
컬럼 6 (F열) DATA.Columns(6) - dbo.Management.EventUser (등록자 - MES_Master.Range('WORKER'))

2. MS-SQL Server 백엔드 구조 (MESDB_CREATE.sql)

MESDB_CREATE.sql에 정의된 백엔드 테이블 DDL 스키마 및 연계 저장 프로시저(Stored Procedure)의 완전한 T-SQL 구현 소스코드입니다.

TABLE [dbo].[Management] DDL Definition

기종 마스터 테이블 DDL 정의

CREATE TABLE [dbo].[Management](
    [Management] [varchar](50) NOT NULL, -- 기종코드 (Primary Key)
    [Name]       [varchar](50) NOT NULL, -- 기종명
    [Type]       [varchar](50) NOT NULL, -- 제품구분 (완제품, 반제품, 원자재)
    [TactTime]   [int] NULL,             -- 표준 택트타임 (초 단위)
    [EventTime]  [datetime] NOT NULL,    -- 등록/수정 일시
    [EventUser]  [varchar](50) NOT NULL, -- 등록/수정 작업자
    CONSTRAINT [PK_Management] PRIMARY KEY CLUSTERED ([Management] ASC)
) ON [PRIMARY]
PROCEDURE [dbo].[Management_Select] Stored Procedure

제품유형에 따른 기종 목록 조회

CREATE PROCEDURE [dbo].[Management_Select](
    @Type varchar(50)
)
AS
BEGIN
    SET NOCOUNT ON
    IF @Type = '전체'
        SELECT * FROM dbo.Management WITH(NOLOCK) ORDER BY Management
    ELSE
        SELECT * FROM dbo.Management WITH(NOLOCK) WHERE [Type] = @Type ORDER BY Management
    RETURN 0
END
PROCEDURE [dbo].[Management_Save] Stored Procedure (UPSERT)

기종 마스터 신규 등록 및 변경(UPSERT)

CREATE PROCEDURE [dbo].[Management_Save](
    @Management varchar(50),
    @Name varchar(50),
    @Type varchar(50),
    @TactTime int,
    @EventTime datetime,
    @EventUser varchar(50) = 'SYSTEM'
)
AS
BEGIN
    SET NOCOUNT ON
    DECLARE @CurrentTime datetime
    SET @CurrentTime = GETDATE()

    -- 1. Management.Type 유효성 검증
    SELECT Code FROM dbo.Code WHERE keyID = 'Management.Type' AND [name] = @Type
    IF @@ROWCOUNT = 0
    BEGIN
        RAISERROR('dbo.Management_Save : Type 오류 [Type = %s]', 16, -1, @Type)
        RETURN -10
    END

    -- 2. UPSERT 분기 처리
    IF (SELECT COUNT(*) FROM dbo.Management WHERE Management = @Management) = 0
        INSERT INTO dbo.Management VALUES(@Management, @Name, @Type, @TactTime, @CurrentTime, @EventUser);
    ELSE
        UPDATE dbo.Management
        SET [Name] = @Name,
            [Type] = @Type,
            TactTime = @TactTime,
            EventTime = @CurrentTime,
            EventUser = @EventUser
        WHERE Management = @Management

    RETURN 0
END
PROCEDURE [dbo].[Management_Delete] Stored Procedure

기종 마스터 삭제

CREATE PROCEDURE [dbo].[Management_Delete](
    @Management varchar(50)
)
AS
BEGIN
    SET NOCOUNT ON
    DELETE FROM dbo.Management WHERE Management = @Management
    IF @@ROWCOUNT = 0
    BEGIN
        RAISERROR('dbo.Management_Delete : 삭제 오류 [Management = %s]', 16, -1, @Management)
        RETURN -10
    END
    RETURN 0
END

4. MES_Management.cls 핵심 프로시저 상세 소스코드 해설

상수/변수 선언 및 Worksheet_Activate() Init Event

시트 활성화 시 드롭다운 콤보 유효성 검사 및 변경추적 배열 초기화

Private Const ThisModuleVersion As Integer = 1
Option Explicit

Private sDataList() As String
Private Const QUERY_SELECT As String = "dbo.Management_Select"
Private Const QUERY___SAVE As String = "dbo.Management_Save"
Private Const QUERY_DELETE As String = "dbo.Management_Delete"

Private Function QuerySelectParameter() As String
    QuerySelectParameter = "'" + Range("TYPE").value + "'"
End Function

Private Function QueryDeleteParameter(iRownumber As Long) As String
    QueryDeleteParameter = "'" + Range("DATA").Cells(iRownumber, 1).text + "'"
End Function

Private Sub AutoChangeValue(iRownumber As Long)
    Range("DATA").Cells(iRownumber, 5).value = DateTime.Now()
    Range("DATA").Cells(iRownumber, 6).value = MES_Master.Range("WORKER").text
End Sub

Private Sub Worksheet_Activate()
    Static bInitflag As Boolean
    If bInitflag = False Then
        ReDim sDataList(Range("DATA").Rows.Count)
        Call RangeCode_Set(Range("DATA").Columns(3), CodeList_Select("Management.Type"))
        Call RangeCode_Set(Range("TYPE"), "전체," & Range("DATA").Columns(3).Validation.Formula1)
        bInitflag = True
    End If
End Sub
💡 핵심 로직 및 현장 적용 포인트:
  • 공통코드 테이블(dbo.Code)에서 Management.Type 항목을 동적으로 읽어와 C열과 상단 필터 셀에 드롭다운을 자동 바인딩합니다.
  • sDataList()는 엑셀 행 단위의 상태(SAVE, DELETE)를 추적하는 내부 상태 머신입니다.
Private Sub cmdDisplay_Click() / cmdSave_Click() CRUD Logic

조회 및 일괄 트랜잭션 저장/삭제 서브루틴

Private Sub cmdDisplay_Click()
    Dim sSQL As String
    Call DeleteLine_Cancel(Range("DATA"))
    sSQL = QUERY_SELECT + " " + QuerySelectParameter()
    Call SelectToRange(sSQL, Range("DATA"))
    ReDim sDataList(Range("DATA").Rows.Count)
    Call DateFromatSet(Range("DATA").Columns(5))
End Sub

Private Sub cmdSave_Click()
    Dim iDataRow As Long, sSQL As String
    For iDataRow = 1 To Range("DATA").Rows.Count
        If sDataList(iDataRow) = "DELETE" Then
            Call DeleteLine_Cancel(Range("DATA").Rows(iDataRow))
            sSQL = QUERY_DELETE + " " + QueryDeleteParameter(iDataRow)
            Call ExecCmd(sSQL)
        ElseIf sDataList(iDataRow) = "SAVE" Then
            sSQL = QUERY___SAVE + " " + DataList_Create(Range("DATA").Rows(iDataRow))
            Call ExecCmd(sSQL)
        End If
        If Range("DATA").Cells(iDataRow, 1) = "" Then Exit For
    Next
    Call cmdDisplay_Click
End Sub
💡 핵심 로직 및 현장 적용 포인트:
  • DataList_Create를 통해 1개 행의 모든 컬럼값을 단일 SQL 파라미터 문자열('MNG001', '기종명', ...)로 직렬화하여 Management_Save SP로 전달합니다.
Private Sub Worksheet_BeforeDoubleClick(ByVal Target As Range, Cancel As Boolean) Screen Routing

기종코드 더블클릭 시 사양/BOM 화면으로 자동 전환

Private Sub Worksheet_BeforeDoubleClick(ByVal Target As Range, Cancel As Boolean)
    'A열의 기종코드 영역을 더블클릭한 경우
    If Change_Check(Target, Range("DATA").Columns(1)) Then
        If Target.Value <> "" Then
            '사양 화면(MES_MngSpec)으로 이동하며 기종코드 자동 바인딩 및 조회
            Call Worksheet_Link(MES_MngSpec, Target.Value)
            Cancel = True
        End If
    End If
End Sub
💡 핵심 로직 및 현장 적용 포인트:
  • 사용자가 특정 기종을 더블클릭하면 Worksheet_Link를 통해 MES_MngSpec.Range("MANAGEMENT")에 기종코드를 주입하고 즉시 사양 화면으로 이동시킵니다.

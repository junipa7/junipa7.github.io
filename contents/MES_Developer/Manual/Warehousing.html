1. MES_Warehousing.cls 자재 입고 및 공정창고 이동 상세 기술 분석서 화면 레이아웃 & UI 컨트롤 분석

MES_Warehousing 화면은 외부 협력사로부터 납품된 원자재(Material)를 신규 입고(In) 처리하고, 생산 라인 투입을 위해 주창고에서 현장 공정창고(WIP Location)로 자재를 이동시키는 자재/재고 물류 관리 화면입니다.

▲ [MES_Warehousing.jpg] 실제 엑셀 클라이언트 구동 화면 (상단 조회조건/ActiveX 버튼 및 DATA 그리드)
구분엑셀 셀 주소명명된 범위 (Name)연계 DB 컬럼 / 컨트롤 설명
자재코드 B1 Range("MATERIAL") 원자재 코드 드롭다운
로케이션 D1 Range("LOCATION") 창고 로케이션 (RAW_WH: 원자재창고, LINE_WH: 공정창고)
데이터 영역 A3:G25 Range("DATA") 입고 및 재고 이동 그리드
ActiveX 버튼 상단 행 cmdInSave, cmdMoveSave [신규 입고 저장], [공정창고 이동 저장]

2. MS-SQL Server 백엔드 구조 (MESDB_CREATE.sql)

MESDB_CREATE.sql에 정의된 백엔드 테이블 DDL 스키마 및 연계 저장 프로시저(Stored Procedure)의 완전한 T-SQL 구현 소스코드입니다.

TABLE [dbo].[MaterialInventory] DDL Definition

자재 재고 테이블 DDL

CREATE TABLE [dbo].[MaterialInventory](
    [MaterialLot] [varchar](50) NOT NULL,
    [Material]    [varchar](50) NOT NULL,
    [Count]       [numeric](18, 3) NOT NULL,
    [Location]    [varchar](50) NOT NULL, -- RAW_WH, LINE_WH 등
    [Status]      [varchar](50) NOT NULL,
    [EventTime]   [datetime] NOT NULL,
    [EventUser]   [varchar](50) NOT NULL,
    CONSTRAINT [PK_MaterialInventory] PRIMARY KEY CLUSTERED ([MaterialLot] ASC)
) ON [PRIMARY]
PROCEDURE [dbo].[Material_Move] Stored Procedure

자재 창고 이동 트랜잭션

CREATE PROCEDURE [dbo].[Material_Move](
    @MaterialLot varchar(50),
    @ToLocation varchar(50),
    @MoveCount numeric(18,3),
    @EventUser varchar(50)
)
AS
BEGIN
    SET NOCOUNT ON
    BEGIN TRANSACTION
    
    -- 1. 기존 재고 차감 및 로케이션 변경
    UPDATE dbo.MaterialInventory
    SET [Location] = @ToLocation, EventTime = GETDATE(), EventUser = @EventUser
    WHERE MaterialLot = @MaterialLot

    -- 2. 이동 이력 테이블 기록
    INSERT INTO dbo.MaterialMoveHistory (MaterialLot, ToLocation, MoveCount, EventTime, EventUser)
    VALUES (@MaterialLot, @ToLocation, @MoveCount, GETDATE(), @EventUser)

    COMMIT TRANSACTION
    RETURN 0
END

Private Sub cmdMoveSave_Click() - 자재 이동 처리 Inventory Move

현장 공정창고 이동 서브루틴

Private Sub cmdMoveSave_Click()
    Dim sSQL As String
    sSQL = "dbo.Material_Move '" & Range("DATA").Cells(1, 1).Value & "', 'LINE_WH', " & Range("DATA").Cells(1, 3).Value & ", '" & MES_Master.Range("WORKER").Text & "'"
    Call ExecCmd(sSQL)
    MsgBox "자재가 공정창고로 이동 처리되었습니다.", vbInformation, "완료"
End Sub

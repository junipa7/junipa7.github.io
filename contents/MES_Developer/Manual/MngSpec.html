1. MES_MngSpec.cls 기종별 공정 사양 관리 상세 기술 분석서 화면 레이아웃 & UI 컨트롤 분석

MES_MngSpec 화면은 특정 기종에 대해 각 제조 공정(외관검사, 특성검사 등)에서 검사해야 할 사양 항목명(두께, 전압, 치수 등), 기준값(Value), 상한치(UpperLimit), 하한치(LowerLimit), 표시순서(OrderSeq)를 설정하는 품질 기준정보 관리 화면입니다. 기준값을 입력하면 상하한치가 자동으로 계산되어 입력 실수를 방지합니다.

컬럼 3 (C열) DATA.Columns(3) - dbo.ManagementSpec.Item (검사 항목명 - varchar(50))

컬럼 5 (E열) DATA.Columns(5) - dbo.ManagementSpec.UpperLimit (상한치 - numeric(18,3), 기본 +10%)
컬럼 6 (F열) DATA.Columns(6) - dbo.ManagementSpec.LowerLimit (하한치 - numeric(18,3), 기본 -10%)
컬럼 7 (G열) DATA.Columns(7) - dbo.ManagementSpec.OrderSeq (출력 순서 - int)
컬럼 8 (H열) DATA.Columns(8) - dbo.ManagementSpec.EventTime (등록일시)
컬럼 9 (I열) DATA.Columns(9) - dbo.ManagementSpec.EventUser (등록자)

2. MS-SQL Server 백엔드 구조 (MESDB_CREATE.sql)

MESDB_CREATE.sql에 정의된 백엔드 테이블 DDL 스키마 및 연계 저장 프로시저(Stored Procedure)의 완전한 T-SQL 구현 소스코드입니다.

TABLE [dbo].[ManagementSpec] DDL Definition

기종별 공정 사양 테이블 DDL 정의

CREATE TABLE [dbo].[ManagementSpec](
    [Management]  [varchar](50) NOT NULL,     -- 기종코드
    [Process]     [smallint] NOT NULL,        -- 공정코드
    [Item]        [varchar](50) NOT NULL,     -- 검사 항목명 (PK 복합키)
    [Value]       [numeric](18, 3) NOT NULL,  -- 기준값
    [UpperLimit]  [numeric](18, 3) NOT NULL,  -- 상한치
    [LowerLimit]  [numeric](18, 3) NOT NULL,  -- 하한치
    [OrderSeq]    [int] NOT NULL,             -- 표시 순서
    [EventTime]   [datetime] NOT NULL,        -- 등록일시
    [EventUser]   [varchar](50) NOT NULL,     -- 등록 작업자
    CONSTRAINT [PK_ManagementSpec] PRIMARY KEY CLUSTERED (
        [Management] ASC, [Process] ASC, [Item] ASC
    )
) ON [PRIMARY]
PROCEDURE [dbo].[ManagementSpec_Select] Stored Procedure

기종별 공정 사양 목록 조회

CREATE PROCEDURE [dbo].[ManagementSpec_Select](
    @Management varchar(50)
)
AS
BEGIN
    SET NOCOUNT ON
    SELECT * FROM dbo.ManagementSpec WITH(NOLOCK)
    WHERE Management = @Management
    ORDER BY Process, OrderSeq
    RETURN 0
END
PROCEDURE [dbo].[ManagementSpec_Save] Stored Procedure (UPSERT)

공정 사양 항목 저장/수정 (UPSERT)

CREATE PROCEDURE [dbo].[ManagementSpec_Save](
    @Management varchar(50),
    @Process smallint,
    @Item varchar(50),
    @Value numeric(18,3),
    @UpperLimit numeric(18,3),
    @LowerLimit numeric(18,3),
    @OrderSeq int,
    @EventTime datetime,
    @EventUser varchar(50) = 'SYSTEM'
)
AS
BEGIN
    SET NOCOUNT ON
    DECLARE @CurrentTime datetime
    SET @CurrentTime = GETDATE()

    -- 1. 기종 및 공정 존재여부 외래키 유효성 검증
    IF NOT EXISTS (SELECT 1 FROM dbo.Management WHERE Management = @Management)
    BEGIN
        RAISERROR('dbo.ManagementSpec_Save : Management 코드 오류 [%s]', 16, -1, @Management)
        RETURN -10
    END

    IF NOT EXISTS (SELECT 1 FROM dbo.Process WHERE Process = @Process)
    BEGIN
        RAISERROR('dbo.ManagementSpec_Save : Process 코드 오류 [%d]', 16, -1, @Process)
        RETURN -20
    END

    -- 2. 복합키(Management + Process + Item) 기준 UPSERT
    IF (SELECT COUNT(*) FROM dbo.ManagementSpec 
        WHERE Management = @Management AND Process = @Process AND Item = @Item) = 0
        INSERT INTO dbo.ManagementSpec 
        VALUES(@Management, @Process, @Item, @Value, @UpperLimit, @LowerLimit, @OrderSeq, @CurrentTime, @EventUser);
    ELSE
        UPDATE dbo.ManagementSpec
        SET [Value] = @Value,
            UpperLimit = @UpperLimit,
            LowerLimit = @LowerLimit,
            OrderSeq = @OrderSeq,
            EventTime = @CurrentTime,
            EventUser = @EventUser
        WHERE Management = @Management AND Process = @Process AND Item = @Item

    RETURN 0
END
PROCEDURE [dbo].[ManagementSpec_Delete] Stored Procedure

공정 사양 항목 삭제

CREATE PROCEDURE [dbo].[ManagementSpec_Delete](
    @Management varchar(50),
    @Process smallint,
    @Item varchar(50)
)
AS
BEGIN
    SET NOCOUNT ON
    DELETE FROM dbo.ManagementSpec 
    WHERE Management = @Management AND Process = @Process AND Item = @Item
    IF @@ROWCOUNT = 0
    BEGIN
        RAISERROR('dbo.ManagementSpec_Delete : 삭제 대상 없음', 16, -1)
        RETURN -10
    END
    RETURN 0
END

3. VBA 클라이언트 동작 라이프사이클 & 상태 관리

1. 시트 초기화
Worksheet_Activate
기종 목록 드롭다운 설정, 공정코드 드롭다운 설정 및 변경추적 배열 초기화
2. 사양 조회
cmdDisplay_Click
선택된 기종코드(Range("MANAGEMENT"))에 매핑된 전체 공정 사양 항목 조회 및 그리드 출력
3. 상하한 자동계산
AutoChangeValue
D열(기준값) 입력 시 E열(상한치 = 값 * 1.1)과 F열(하한치 = 값 * 0.9) 자동 계산 및 등록일시 갱신
4. 삭제 플래그
cmdDelete_Click
선택된 사양 행 취소선 설정 및 sDataList(row) = 'DELETE' 플래그 지정

cmdSave_Click
복합키 파라미터를 조립하여 ManagementSpec_Save/Delete 일괄 트랜잭션 실행

4. MES_MngSpec.cls 핵심 프로시저 상세 소스코드 해설

AutoChangeValue(iRownumber) - 상하한치 자동 산출 로직 Auto Calculation

기준값(Value) 입력 시 상하한치를 ±10%로 자동 계산하는 핵심 알고리즘

Private Sub AutoChangeValue(iRownumber As Long)
    Dim vVal As Double
    '1열(기종)이 비어있으면 상단 조회조건의 기종코드를 자동 주입
    If Range("DATA").Cells(iRownumber, 1).Value = "" Then
        Range("DATA").Cells(iRownumber, 1).Value = Range("MANAGEMENT").Value
    End If
    
    '4열(기준값)이 숫자형태로 입력된 경우 상하한치 자동 계산 (±10%)
    If IsNumeric(Range("DATA").Cells(iRownumber, 4).Value) Then
        vVal = CDbl(Range("DATA").Cells(iRownumber, 4).Value)
        If Range("DATA").Cells(iRownumber, 5).Value = "" Then
            Range("DATA").Cells(iRownumber, 5).Value = Round(vVal * 1.1, 3) '상한치 (+10%)
        End If
        If Range("DATA").Cells(iRownumber, 6).Value = "" Then
            Range("DATA").Cells(iRownumber, 6).Value = Round(vVal * 0.9, 3) '하한치 (-10%)
        End If
    End If
    
    '등록일시 및 작업자 자동 설정
    Range("DATA").Cells(iRownumber, 8).Value = DateTime.Now()
    Range("DATA").Cells(iRownumber, 9).Value = MES_Master.Range("WORKER").Text
End Sub
💡 핵심 로직 및 현장 적용 포인트:
  • 현장 작업자가 기준값(예: 100)만 입력하면 상한치(110)와 하한치(90)를 엑셀 VBA가 즉시 자동 산출하여 수동 계산 실수를 방지합니다.
  • 필요 시 사용자가 상하한치를 임의로 수정할 수도 있습니다.
Worksheet_Change 이벤트 제어 Event Handler

이벤트 연쇄(무한루프) 방지 및 유효성 검사

Private Sub Worksheet_Change(ByVal Target As Range)
    Dim iDataRow As Long
    If Application.ScreenUpdating = False Then Exit Sub

    If Change_Check(Target, Range("DATA")) Then
        iDataRow = Target.Row - Range("DATA").Row + 1
        Application.ScreenUpdating = False
        Call AutoChangeValue(iDataRow)
        Application.ScreenUpdating = True
        
        If AllDataInput_Check(Range("DATA").Rows(iDataRow)) Then
            sDataList(iDataRow) = "SAVE"
        End If
    End If
End Sub
💡 핵심 로직 및 현장 적용 포인트:
  • Application.ScreenUpdating = False를 통해 AutoChangeValue 실행 중 다시 Worksheet_Change가 트리거되는 이벤트 무한 재귀 호출을 원천 차단합니다.

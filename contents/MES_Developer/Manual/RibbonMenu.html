modRibbonMenu.bas 상세 분석 및 실무 해설서

Excel CustomUI Ribbon XML과 VBA 비즈니스 로직을 연결하는 리본 메뉴 콜백 이벤트 컨트롤러

모듈 명칭
modRibbonMenu
핵심 도메인
CustomUI XML / Callbacks
지원 함수/프로시저
11개 (Pub 10 / Priv 1)
연동 라이브러리
IRibbonControl

1. 모듈 개요 및 리본 아키텍처

modRibbonMenu 모듈은 Excel 상단 탭 메뉴(CustomUI Ribbon XML)에 배치된 사용자 정의 MES 메뉴(작업자 변경, 서버 선택, 공정 화면 생성, 핫패칭 저장/로드 등)의 사용자 액션을 가로채어 VBA 비즈니스 로직과 양방향으로 동기화하는 컨트롤러입니다.

사용자 인증 (UserInfo)
인프라 분기 (ServerInfo)
화면 생성 (Process)
배포 자동화 (OTA)

2. 작업자 & DB 서버 양방향 동기화 콜백

Sub MES_Master_User_getText / MES_Master_User_Change Public Sub

리본 메뉴의 작업자 텍스트박스 초기 로드 시 엑셀 MES_Master 시트의 WORKER 명명 범위를 읽어오고, 리본에서 수정 시 워크시트에 즉시 반영합니다.

' Callback for MES_UserInfo getText (리본 UI 렌더링 시 값 전달)
Sub MES_Master_User_getText(control As IRibbonControl, ByRef returnedVal)
    returnedVal = MES_Master.Range("WORKER").text
End Sub

' Callback for MES_UserInfo onChange (사용자가 리본에서 수정 시)
Sub MES_Master_User_Change(control As IRibbonControl, text As String)
    MES_Master.Range("WORKER").value = text
End Sub
Sub MES_Master_Server / MES_Master_Server_getText Public Sub

리본 메뉴의 서버 선택 드롭다운/입력값과 엑셀 시트 Range("SERVER") 셀을 실시간으로 동기화합니다.

Sub MES_Master_Server(control As IRibbonControl, text As String)
    Range("SERVER").value = text
End Sub

Sub MES_Master_Server_getText(control As IRibbonControl, ByRef returnedVal)
    returnedVal = Range("SERVER").text
End Sub

3. 네비게이션 및 모듈 배포 트리거

Sub conMES_Product_Process(control As IRibbonControl) Public Sub

리본에서 [공정 관리 생성] 버튼 클릭 시 modExt의 Create_MES_Product_Process를 호출하여 화면을 동적으로 빌드합니다.

Sub MES_ProgramSave / MES_ProgramLoad Public Sub

리본에서 [모듈 저장] 및 [모듈 로딩] 클릭 시 modUpgrade의 핫패칭 프로시저를 직접 호출합니다.

Sub MES_ProgramSave(control As IRibbonControl)
    Call UpgradeModuleSave
End Sub

Sub MES_ProgramLoad(control As IRibbonControl)
    Call UpgradeModuleLoad
End Sub

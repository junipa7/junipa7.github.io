MES_MngDisplay.cls 기종별 사양/BOM 종합조회 상세 기술 분석서

기종 마스터 정보, 공정별 검사 사양 데이터 및 다계층 BOM TreeView를 단일 엑셀 시트에 통합 표출하는 종합 대시보드

화면 모듈
MES_MngDisplay.cls
매핑 백엔드 테이블
Management / ManagementSpec / BOM
연계 저장 프로시저
Management_Select / Spec_Select / TreeSelect
ActiveX 컨트롤
MSComctlLib.TreeCtrl (ActiveX TreeView)

1. MES_MngDisplay.cls 기종별 사양/BOM 종합조회 상세 기술 분석서 화면 레이아웃 & UI 컨트롤 분석

MES_MngDisplay 화면은 제품 생산에 필요한 모든 기준정보(기종 기본정보, 공정별 사양치, 자재명세서 TreeView)를 하나의 엑셀 화면에서 원스톱으로 조회할 수 있는 읽기 전용(Read-Only) 종합 대시보드 화면입니다.

▲ [MES_MngDisplay.jpg] 실제 엑셀 클라이언트 구동 화면 (상단 조회조건/ActiveX 버튼 및 DATA 그리드)
구분엑셀 셀 주소명명된 범위 (Name)연계 DB 컬럼 / 컨트롤 설명
기종 선택 B1 Range("MANAGEMENT") 조회 대상 제품 기종코드 드롭다운
ActiveX 버튼 상단 행 cmdDisplay [종합 조회] 버튼 (단일 클릭으로 3대 데이터셋 동시 로드)
기본정보 영역 A3:D4 Range("MNG_DATA") 기종명, 제품유형, 표준 택트타임 출력 그리드
사양정보 영역 A7:G20 Range("SPEC_DATA") 공정별 검사 항목, 기준값, 상하한치 출력 그리드
ActiveX TreeView 우측 영역 TreeView1 ActiveX TreeView 컨트롤 (다단계 계층형 BOM 전개)

2. MS-SQL Server 백엔드 구조 (MESDB_CREATE.sql)

MESDB_CREATE.sql에 정의된 백엔드 테이블 DDL 스키마 및 연계 저장 프로시저(Stored Procedure)의 완전한 T-SQL 구현 소스코드입니다.

다중 쿼리 연동 아키텍처 Multi-Query Architecture

단일 화면에서 3개의 저장 프로시저를 순차적으로 실행하여 시트 영역 및 ActiveX 컨트롤에 분기 매핑

-- 1. 기종 기본 정보 조회
EXEC dbo.Management_Select @Type = '전체';

-- 2. 기종별 공정 검사 사양 조회
EXEC dbo.ManagementSpec_Select @Management = 'MNG001';

-- 3. 기종별 다계층 BOM 트리 데이터 조회
EXEC dbo.BillOfMaterial_TreeSelect @Management = 'MNG001';

3. VBA 클라이언트 동작 라이프사이클 & 상태 관리

1. 기종 선택
Range('MANAGEMENT')
상단 B1 셀에서 조회하고자 하는 제품 기종 선택
2. 종합 조회 실행
cmdDisplay_Click
단 1회 클릭으로 3대 저장 프로시저를 연속 호출하여 화면 영역별로 데이터 출력
3. TreeView 바인딩
SelectToTreeview
modADO.SelectToTreeview를 통해 ActiveX TreeView1 컨트롤에 노드 계층 생성

4. MES_MngDisplay.cls 핵심 프로시저 상세 소스코드 해설

Private Sub cmdDisplay_Click() - 종합 데이터 로딩 Dashboard Controller

단일 프로시저에서 3개 영역(기본정보, 사양그리드, TreeView)을 동시 바인딩

Private Sub cmdDisplay_Click()
    Dim sSQL As String
    Dim sMngCode As String
    
    sMngCode = Range("MANAGEMENT").Value
    If sMngCode = "" Then
        MsgBox "조회할 기종을 선택하세요.", vbExclamation, "알림"
        Exit Sub
    End If
    
    '1. 기종 기본정보 조회 및 출력
    sSQL = "dbo.Management_Select '전체'"
    Call SelectToRange(sSQL, Range("MNG_DATA"))
    
    '2. 공정 사양 정보 조회 및 출력
    sSQL = "dbo.ManagementSpec_Select '" & sMngCode & "'"
    Call SelectToRange(sSQL, Range("SPEC_DATA"))
    
    '3. 계층형 BOM TreeView 컨트롤 바인딩
    sSQL = "dbo.BillOfMaterial_TreeSelect '" & sMngCode & "'"
    Call SelectToTreeview(sSQL, TreeView1)
End Sub
💡 핵심 로직 및 현장 적용 포인트:
  • SelectToTreeview는 SQL 결과셋의 NodePath를 분석하여 ActiveX TreeView1에 Root & Child Node를 자동으로 구성합니다.

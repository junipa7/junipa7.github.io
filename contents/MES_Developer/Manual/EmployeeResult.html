1. MES_EmployeeResult.cls 작업자별 생산실적 통계 상세 기술 분석서 화면 레이아웃 & UI 컨트롤 분석

MES_EmployeeResult 화면은 지정된 기간 동안 작업자별로 수행한 공정 건수, 총 생산수량(ResultCount), 총 불량수량(BadCount) 및 불량률(%)을 통계적으로 집계하여 작업자별 생산성 및 품질 기여도를 평가하는 리포트 화면입니다.

2. MS-SQL Server 백엔드 구조 (MESDB_CREATE.sql)

MESDB_CREATE.sql에 정의된 백엔드 테이블 DDL 스키마 및 연계 저장 프로시저(Stored Procedure)의 완전한 T-SQL 구현 소스코드입니다.

PROCEDURE [dbo].[EmployeeResult_Select] Stored Procedure (Aggregation)

작업자별 실적 통계 집계 쿼리

CREATE PROCEDURE [dbo].[EmployeeResult_Select](
    @FromDate varchar(10),
    @ToDate varchar(10),
    @Worker varchar(50)
)
AS
BEGIN
    SET NOCOUNT ON
    SELECT 
        Worker,
        COUNT(DISTINCT LotID) AS TotalLots,
        COUNT(*) AS TotalProcesses,
        SUM(ResultCount) AS TotalGoodCount,
        SUM(BadCount) AS TotalBadCount,
        CAST(CASE WHEN (SUM(ResultCount) + SUM(BadCount)) = 0 THEN 0 
             ELSE (SUM(BadCount) * 100.0) / (SUM(ResultCount) + SUM(BadCount)) END AS numeric(5,2)) AS DefectRate
    FROM dbo.ProcessResult WITH(NOLOCK)
    WHERE EventTime >= @FromDate AND EventTime <= DATEADD(DAY, 1, @ToDate)
      AND (@Worker = '전체' OR Worker = @Worker)
    GROUP BY Worker
    ORDER BY TotalGoodCount DESC
    RETURN 0
END

Private Sub cmdDisplay_Click() - 집계 리포트 조회 Report Controller

작업자별 통계 데이터 바인딩

Private Sub cmdDisplay_Click()
    Dim sSQL As String
    sSQL = "dbo.EmployeeResult_Select '" & Range("FROM_DATE").Value & "', '" & Range("TO_DATE").Value & "', '" & Range("WORKER").Value & "'"
    Call SelectToRange(sSQL, Range("DATA"))
End Sub

1. 모듈 개요 및 핵심 역할

modExt(Extension Utility) 모듈은 두 가지 특수 목적을 수행합니다:

  • 보안 및 배포 클리닝 (DeleteVBA): 현장 작업자나 외부에 엑셀 시트 결과물만 전달할 때, 내부 비즈니스 로직과 데이터베이스 접속 정보가 담긴 모든 VBA 매크로 및 숨겨진 다이얼로그/구버전 매크로 시트를 안전하게 파괴/제거합니다.
  • 동적 MES 화면 생성 (Create_MES_Product_Process): 공정 관리용 표준 UI 양식을 코드를 통해 신규 워크시트에 실시간으로 생성하고, 셀 서식, 테두리, 배경색, 명명된 범위(Defined Names), 그리고 ActiveX 버튼(조회/삭제/저장)을 픽셀 단위로 자동 배치합니다.

2. 배포용 VBA 코드 완전 삭제 (DeleteVBA)

Sub DeleteVBA(wb As Workbook) Public Sub

대상 통합문서(wb)의 모든 VBA 구성요소(표준 모듈, 클래스, 유저폼, 시트 코드)와 레거시 매크로 시트를 완전히 제거합니다.

Sub DeleteVBA(wb As Workbook)
    Dim c As Object
    Dim k As Long
    
    With wb.VBProject
        If .Protection = 1 Then
            MsgBox "보호된 프로젝트입니다!", vbExclamation, Application.UserName
        Else
            For Each c In .VBComponents
                Select Case c.Type
                    Case 100 ' 시트 모듈 (vbext_ct_Document)
                        k = c.CodeModule.CountOfLines
                        c.CodeModule.DeleteLines 1, k
                    Case 1 ' 표준 모듈 (vbext_ct_StdModule), 클래스/폼(2, 3)
                        .VBComponents.Remove c
                End Select
            Next c
        End If
    End With
    
    Dim D As DialogSheet
    Dim S As Object
    
    ' 매크로 시트 및 다이얼로그 시트 제거
    Application.DisplayAlerts = False
    For Each D In wb.DialogSheets
        D.Delete
    Next D
    For Each S In wb.Sheets
        If S.Type = xlExcel4MacroSheet Then
            S.Delete
        End If
    Next S
    Application.DisplayAlerts = True
End Sub
💡 상세 메커니즘 분석:
  • 컴포넌트 유형별 차별 삭제:
    • c.Type = 100 (Sheet/ThisWorkbook): 엑셀 객체 자체는 삭제할 수 없으므로 CodeModule.DeleteLines 1, k를 사용하여 코드 내용만 비웁니다.
    • c.Type = 1, 2, 3 (Standard Module, Class, UserForm): VBComponents.Remove c를 호출하여 프로젝트 트리에서 모듈 자체를 제거합니다.
  • 보안 레거시 시트 정밀 제거: 악의적이거나 비인가된 수식이 숨어있을 수 있는 Excel 4.0 매크로 시트(xlExcel4MacroSheet) 및 DialogSheets를 경고창 없이(DisplayAlerts = False) 일괄 제거합니다.

3. 공정 관리 표준 시트 동적 생성 (Create_MES_Product_Process)

Sub Create_MES_Product_Process() Public Sub

신규 워크시트를 추가하고 공정 관리 폼 구조, 서식, 명명된 범위, ActiveX 버튼을 자동으로 빌드합니다.

Sub Create_MES_Product_Process()
    Dim xObject As Object
    Dim NewSheet As Worksheet
    
    Set NewSheet = Worksheets.Add
    NewSheet.Name = "공정"
    NewSheet.Activate

    ' 1. 기본 레이아웃 헤더 설정
    Range("A1").FormulaR1C1 = "공정"
    Range("B1").FormulaR1C1 = "완제품"
    Range("A3").FormulaR1C1 = "공정코드"
    Range("B3").FormulaR1C1 = "공정명"
    Range("C3").FormulaR1C1 = "입력구분"
    Range("D3").FormulaR1C1 = "설비"
    Range("E3").FormulaR1C1 = "작업장"
    Range("F3").FormulaR1C1 = "등록일시"
    Range("G3").FormulaR1C1 = "등록자"

    ' 2. B1 핵심 셀 스타일 (노란색 강조)
    With Range("B1").Interior
        .Pattern = xlSolid
        .Color = 65535 ' Yellow
    End With

    ' 3. 테두리 및 헤더 테마 색상 서식 적용
    With Range("A1:B1").Borders
        .LineStyle = xlContinuous
        .Weight = xlThin
    End With
    With Range("A1, A3:G3").Interior
        .Pattern = xlSolid
        .ThemeColor = xlThemeColorDark1
        .TintAndShade = -0.15
    End With
    With Range("A3:G25").Borders
        .LineStyle = xlContinuous
        .Weight = xlThin
    End With

    ' 4. ActiveX 커맨드 버튼 동적 배치 (조회, 삭제, 저장)
    Set xObject = ActiveSheet.OLEObjects.Add(ClassType:="Forms.CommandButton.1", Left:=175, Top:=1, Width:=65, Height:=22)
    xObject.Name = "cmdDisplay"
    xObject.Object.Caption = "조회"

    Set xObject = ActiveSheet.OLEObjects.Add(ClassType:="Forms.CommandButton.1", Left:=250, Top:=1, Width:=65, Height:=22)
    xObject.Name = "cmdDelete"
    xObject.Object.Caption = "삭제"

    Set xObject = ActiveSheet.OLEObjects.Add(ClassType:="Forms.CommandButton.1", Left:=325, Top:=1, Width:=65, Height:=22)
    xObject.Name = "cmdSave"
    xObject.Object.Caption = "저장"

    ' 5. 데이터 바인딩용 명명된 범위 생성
    NewSheet.Names.Add Name:="WORK", RefersToR1C1:="=공정!R1C2"
    NewSheet.Names.Add Name:="DATA", RefersToR1C1:="=공정!R3C1"
End Sub

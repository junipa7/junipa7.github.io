🏭 MES 관련 표준 및 대표 웹사이트 정리

Manufacturing Execution System(제조 실행 시스템) 관련 국제·국내 표준과 대표 웹사이트 정리입니다.

📌 MES 구축 시 최우선 참조 표준 요약

ISA-95 (IEC 62264)가 MES 영역의 사실상 글로벌 마스터 표준이며, 대부분의 MES 솔루션과 컨설팅 프레임워크가 이 모델을 기반으로 설계됩니다.

MES 핵심 구조   →  ISA-95 (IEC 62264)     ← 가장 중요
MES 기능 정의   →  MESA 11-Function Model
MES KPI        →  ISO 22400
데이터 통신     →  OPC UA (IEC 62541) + ISA-95 Companion Spec
반도체/디스플레이 →  SEMI E5 / E30 / E90 / E95
스마트팩토리    →  RAMI 4.0 (DIN SPEC 91345)

1. 핵심 MES 표준

표준 번호 표준명 주요 내용 대표 웹사이트
ISA-95
(IEC 62264)		 Enterprise-Control System Integration 기업-제어 시스템 간 통합 모델 (레벨 3~4). MES의 가장 핵심적인 참조 모델 isa.org/isa95
ISA-88
(IEC 61512)		 Batch Control 배치 제어 표준. ISA-95와 함께 MES 구조화의 기반 isa.org/isa88
ISO 22400 Manufacturing Operations Management — KPIs 제조 운영 관리를 위한 핵심성과지표(KPI) 정의 iso.org/iso-22400

2. 아키텍처 & 통합 표준

표준 번호 표준명 주요 내용 대표 웹사이트
IEC 62264 Enterprise-control system integration ISA-95의 IEC 국제표준화 버전 (Part 1~6) iec.ch
ISO 15704 Enterprise Integration — Framework 기업 통합 참조 아키텍처 (GERAM 기반) iso.org
IEC 62890 Life-cycle management for products and systems 제품/시스템의 수명주기 관리 iec.ch
DIN SPEC 91345 Reference Architecture Model Industrie 4.0 (RAMI 4.0) 독일 인더스트리 4.0 참조 아키텍처. MES 레이어 포함 plattform-i40.de

3. 데이터 통신 & 인터페이스 표준

표준 번호 표준명 주요 내용 대표 웹사이트
IEC 62541
(OPC UA)		 OPC Unified Architecture 산업 통신 표준. MES-설비 간 데이터 연동의 사실상 표준 opcfoundation.org
MTConnect Manufacturing Data Standard CNC/기계 데이터 수집 표준. MES 실시간 데이터 수집에 활용 mtconnect.org
ISA-95 Companion Spec ISA-95 Information Model over OPC UA ISA-95 모델을 OPC UA로 구현한 스펙 opcfoundation.org
SEMI E5 / E30 / E90 SEMI Equipment Communications 반도체/디스플레이 설비 통신 표준. 해당 산업 MES 필수 semi.org

표준 번호 표준명 주요 내용 대표 웹사이트

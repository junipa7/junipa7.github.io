3. Windows 개인 노트북 MS-SQL 환경 구축 절차

  1. SQL Server Express (DB 엔진) 설치
    MS 공식 사이트에서 무료 버전인 SQL Server Express 인스톨러를 다운로드하여 실행한 뒤, 기본(Basic) 설치를 선택하여 완료합니다.
  2. SSMS (SQL Server Management Studio) 다운로드
    DB 관리 및 쿼리 작성을 위한 도구인 SSMS 최신 설치 파일(SSMS-Setup-*.exe)을 MS 공식 페이지에서 다운로드합니다.
  3. SSMS 설치 및 재부팅
    설치 파일을 실행하여 설치(Install)를 진행하고, 설치가 완료되면 시스템 안내에 따라 컴퓨터를 재부팅합니다.
  4. SSMS 실행 및 로컬 서버 연결
    SSMS를 실행하고 아래 정보로 연결합니다:
    • 서버 유형(Server type): Database Engine
    • 서버 이름(Server name): localhost 또는 .\SQLEXPRESS
    • 인증(Authentication): Windows Authentication (Windows 인증)
💡 참고: 연결 후 SSMS 상단의 [새 쿼리(New Query)] 버튼을 클릭하여 SQL 스크립트를 작성하고 실행(F5)할 수 있습니다.

4. 엑셀 데이터를 MS-SQL Insert 쿼리로 변환하는 스크립트

DATA_20230221.xls 파일을 읽어 각 시트별 데이터 타입을 자동 판별하고, 따옴표 및 NULL 처리 등을 반영하여 .sql 파일로 일괄 생성하는 Python 코드입니다.

사전 준비 (라이브러리 설치)

터미널(CMD/PowerShell)에서 아래 명령어를 실행하세요.
pip install pandas xlrd openpyxl

Python 스크립트 코드

import os
import pandas as pd
import numpy as np

# 파일 경로 설정
excel_path = r"C:\Users\junipa7\Documents\myhomepage\contents\MES_Developer\DATA_20230221.xls"
output_sql_path = r"C:\Users\junipa7\Documents\myhomepage\contents\MES_Developer\DATA_20230221_insert.sql"

def format_sql_val(val):
    if pd.isna(val) or val is None or str(val).strip() in ('', 'NaT', 'nan', 'None'):
        return "NULL"
    if isinstance(val, (int, np.integer)):
        return str(val)
    if isinstance(val, (float, np.floating)):
        return str(int(val)) if val.is_integer() else str(val)
    if isinstance(val, bool):
        return "1" if val else "0"
    if isinstance(val, (pd.Timestamp, str)):
        val_str = str(val).replace("'", "''")
        return f"'{val_str}'"
    
    val_str = str(val).replace("'", "''")
    return f"'{val_str}'"

def generate_insert_sql(excel_file, output_file):
    excel_data = pd.ExcelFile(excel_file)
    
    with open(output_file, "w", encoding="utf-8") as f:
        f.write("-- MS-SQL Insert Statements Generated from Excel\n")
        f.write(f"-- Source: {excel_file}\n\n")
        
        for sheet_name in excel_data.sheet_names:
            df = pd.read_excel(excel_file, sheet_name=sheet_name)
            
            if df.empty:
                continue
                
            table_name = sheet_name.strip()
            columns = [f"[{col.strip()}]" for col in df.columns]
            col_list_str = ", ".join(columns)
            
            f.write(f"-- Table: {table_name}\n")
            
            for _, row in df.iterrows():
                formatted_values = [format_sql_val(val) for val in row]
                val_list_str = ", ".join(formatted_values)
                sql = f"INSERT INTO [{table_name}] ({col_list_str}) VALUES ({val_list_str});\n"
                f.write(sql)
            
            f.write("\n")
            
    print(f"SQL 파일 생성이 완료되었습니다: {output_file}")

if __name__ == "__main__":
    generate_insert_sql(excel_path, output_sql_path)
  • 데이터 타입 판별: 숫자(Int/Float)는 따옴표 없이 처리, 문자열 및 날짜는 '값'으로 감싸며 내부 작은따옴표는 ''로 이스케이프 처리합니다.
  • NULL 처리: 빈 셀(NaN, 빈 문자열)은 NULL로 변환합니다.
  • 예약어 방지: 시트명 및 컬럼명에 대괄호([컬럼명])를 적용하여 MS-SQL 예약어 충돌을 방지합니다.

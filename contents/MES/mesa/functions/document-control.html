문서 및 작업표준 관리

Document Control 기반 MES 기능 정리

MESA MES FunctionISA-95 Level 3

목적

작업 지시서, SOP, Recipe, 검사 기준서, 안전 지침, 도면의 최신 버전을 작업 시점에 맞게 제공하고 열람 이력을 남깁니다.

문서 관리는 단순 게시판이 아닙니다. 작업이 시작되는 시점에 어떤 기준서가 유효했는지를 증명할 수 있어야 하며, 변경점이 Lot이나 Serial 이력과 연결되어야 합니다.

기능 범위

주요 범위
  • SOP/작업표준 버전 관리
  • 작업별 문서 연결
  • 전자 서명/승인
  • Recipe와 문서 동기화
  • 개정 이력 추적
입력 정보
  • PLM/문서관리 시스템
  • 공정 라우팅
  • 제품/공정 변경 통보
  • 품질 기준
  • EHS 문서
출력 정보
  • 작업 문서 표시
  • 문서 열람 이력
  • 개정 적용 이력
  • 전자 승인 기록
  • 작업 기준 위반 알림

구현/운영 체크포인트

기준정보ERP, PLM, 설비 기준정보와 키 체계를 맞추고 변경 이력을 남깁니다.
현장 실행작업자가 실제로 쓰는 화면, 스캔, 승인, 예외 처리 흐름을 우선 설계합니다.
감사 추적누가, 언제, 어떤 기준으로 실행/변경/승인했는지 추적 가능해야 합니다.

상세 생산 스케줄링

Operations / Detail Scheduling 기반 MES 기능 정리

MESA MES FunctionISA-95 Level 3

목적

상위 계획을 현장 실행 단위로 쪼개고, 공정 순서, 설비 능력, 셋업, 자재 준비, 우선순위를 반영해 상세 작업 순서를 만듭니다.

MESA 관점의 상세 스케줄은 현장의 실제 제약을 반영해야 합니다. MES는 APS가 만든 계획을 그대로 표시하는 것에서 끝나지 않고, 실행 직전의 상태로 재계산하거나 재정렬할 수 있어야 합니다.

기능 범위

주요 범위
  • 라인/설비별 작업 순서
  • Setup/Changeover 고려
  • 제약 기반 우선순위
  • 긴급오더 삽입
  • Dispatch List 생성
입력 정보
  • ERP/MRP 계획오더
  • BOM/BOP/라우팅
  • 설비 캘린더
  • 자재 가용성
  • 납기와 우선순위
출력 정보
  • 작업 지시 후보
  • 라인별 상세 스케줄
  • Dispatch Queue
  • 스케줄 변경 이력
  • 계획 대비 실행 차이

구현/운영 체크포인트

기준정보ERP, PLM, 설비 기준정보와 키 체계를 맞추고 변경 이력을 남깁니다.
현장 실행작업자가 실제로 쓰는 화면, 스캔, 승인, 예외 처리 흐름을 우선 설계합니다.
감사 추적누가, 언제, 어떤 기준으로 실행/변경/승인했는지 추적 가능해야 합니다.

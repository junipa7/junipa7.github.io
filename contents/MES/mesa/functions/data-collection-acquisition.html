MESA MES 기능 / 데이터 수집

데이터 수집

Data Collection / Acquisition 기반 MES 기능 정리

MESA MES FunctionISA-95 Level 3

목적

설비, 작업자 입력, 검사 장비, Barcode/RFID, SCADA/PLC, EAP로부터 생산 실행 데이터를 수집해 Lot/공정/시간 문맥과 연결합니다.

수집 데이터는 값 자체보다 문맥이 중요합니다. 어떤 Lot, 어떤 공정, 어떤 설비 상태에서 나온 값인지 연결되어야 품질 분석과 KPI 계산에 사용할 수 있습니다.

기능 범위

주요 범위
  • 수동/자동 데이터 수집
  • 설비 이벤트/공정값
  • 작업 실적
  • 검사 결과
  • 데이터 품질 코드
입력 정보
  • PLC/SCADA/EAP
  • 작업자 입력
  • 검사 장비
  • Barcode/RFID
  • ERP 기준정보
출력 정보
  • 원시 데이터
  • 정규화 데이터
  • 검사/공정 이력
  • 실적 집계
  • 데이터 품질 알림

구현/운영 체크포인트

기준정보ERP, PLM, 설비 기준정보와 키 체계를 맞추고 변경 이력을 남깁니다.
현장 실행작업자가 실제로 쓰는 화면, 스캔, 승인, 예외 처리 흐름을 우선 설계합니다.
감사 추적누가, 언제, 어떤 기준으로 실행/변경/승인했는지 추적 가능해야 합니다.

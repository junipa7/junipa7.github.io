작업 단위 디스패칭

Dispatching Production Units 기반 MES 기능 정리

MESA MES FunctionISA-95 Level 3

목적

Lot, Batch, Serial, Carrier, Work Order 같은 생산 단위를 특정 설비나 작업자에게 내려보내고 착수, 보류, 재작업, 완료 흐름을 제어합니다.

디스패칭은 MES의 현장 실행성이 가장 잘 드러나는 기능입니다. 계획과 실제 사이의 마지막 게이트이며, 품질/자재/설비/작업자 조건을 통과한 작업만 착수되어야 합니다.

기능 범위

주요 범위
  • 작업 착수/중지/완료
  • Lot/Batch 우선순위
  • Hold/Release
  • Rework/Reroute
  • 작업자 작업 목록
입력 정보
  • Dispatch Queue
  • 작업 지시
  • 작업 가능 자원
  • 품질 Hold 정보
  • 자재 준비 상태
출력 정보
  • 작업 시작 이벤트
  • 작업 완료 이벤트
  • Hold/Release 이력
  • 실적 보고
  • WIP 상태

구현/운영 체크포인트

기준정보ERP, PLM, 설비 기준정보와 키 체계를 맞추고 변경 이력을 남깁니다.
현장 실행작업자가 실제로 쓰는 화면, 스캔, 승인, 예외 처리 흐름을 우선 설계합니다.
감사 추적누가, 언제, 어떤 기준으로 실행/변경/승인했는지 추적 가능해야 합니다.

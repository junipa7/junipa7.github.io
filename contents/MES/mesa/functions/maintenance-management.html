설비 보전 관리

Maintenance Management 기반 MES 기능 정리

MESA MES FunctionISA-95 Level 3

목적

설비 예방보전, 고장, 보전 작업, Spare Part, 보전 후 재가동 승인 상태를 생산 실행과 연결합니다.

MES의 보전 관리는 CMMS와 겹칠 수 있지만, 핵심은 생산 실행과 연결되는 지점입니다. 설비가 생산에 투입 가능한지, 보전 후 검증이 끝났는지가 MES에서 보여야 합니다.

기능 범위

주요 범위
  • 예방보전 일정
  • 고장/정지 이력
  • 보전 작업 지시
  • Spare Part 사용
  • 보전 후 품질 확인
입력 정보
  • 설비 상태
  • Run Hour/Shot Count
  • 보전 기준
  • 고장 알람
  • Spare Part 재고
출력 정보
  • PM 작업
  • 정비 이력
  • MTBF/MTTR
  • 설비 Release
  • 보전 KPI

구현/운영 체크포인트

기준정보ERP, PLM, 설비 기준정보와 키 체계를 맞추고 변경 이력을 남깁니다.
현장 실행작업자가 실제로 쓰는 화면, 스캔, 승인, 예외 처리 흐름을 우선 설계합니다.
감사 추적누가, 언제, 어떤 기준으로 실행/변경/승인했는지 추적 가능해야 합니다.

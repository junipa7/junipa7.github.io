MESA MES 기능 / 공정 관리

공정 관리

Process Management 기반 MES 기능 정리

MESA MES FunctionISA-95 Level 3

목적

공정 조건, Recipe, 작업 순서, Parameter, 공정 상태를 관리하고 표준 조건에서 벗어난 실행을 감지합니다.

공정 관리는 장비 제어와 품질의 중간에 있습니다. MES는 어떤 조건으로 생산했는지 증명하고, 승인되지 않은 조건 변경을 막아야 합니다.

기능 범위

주요 범위
  • Recipe/Parameter 관리
  • 공정 조건 검증
  • 공정 상태 추적
  • Run 조건 비교
  • 공정 변경 이력
입력 정보
  • BOP/라우팅
  • Recipe
  • 공정 Parameter
  • 설비 상태
  • 품질 Feedback
출력 정보
  • 공정 실행 이력
  • Recipe Download 이력
  • Parameter 편차 알림
  • 공정 조건 승인
  • Run Summary

구현/운영 체크포인트

기준정보ERP, PLM, 설비 기준정보와 키 체계를 맞추고 변경 이력을 남깁니다.
현장 실행작업자가 실제로 쓰는 화면, 스캔, 승인, 예외 처리 흐름을 우선 설계합니다.
감사 추적누가, 언제, 어떤 기준으로 실행/변경/승인했는지 추적 가능해야 합니다.

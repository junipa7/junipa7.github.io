성과 분석

Performance Analysis 기반 MES 기능 정리

MESA MES FunctionISA-95 Level 3

목적

생산성, 품질, 납기, 설비 효율, 작업자 효율, 병목, 손실 시간을 분석해 운영 개선 지표를 제공합니다.

성과 분석은 MES 데이터의 결과물입니다. 계산식보다 중요한 것은 상태/품질/계획/실적 데이터의 시간 기준과 분류 기준을 통일하는 것입니다.

기능 범위

주요 범위
  • OEE/가동률
  • Throughput
  • Cycle Time
  • Yield
  • Loss Pareto
  • Plan vs Actual
입력 정보
  • 실적 이벤트
  • 설비 상태
  • 품질 결과
  • 계획 데이터
  • 작업자/자원 이력
출력 정보
  • KPI Dashboard
  • Loss 분석
  • 병목 분석
  • 추세/알림
  • 개선 과제

구현/운영 체크포인트

기준정보ERP, PLM, 설비 기준정보와 키 체계를 맞추고 변경 이력을 남깁니다.
현장 실행작업자가 실제로 쓰는 화면, 스캔, 승인, 예외 처리 흐름을 우선 설계합니다.
감사 추적누가, 언제, 어떤 기준으로 실행/변경/승인했는지 추적 가능해야 합니다.

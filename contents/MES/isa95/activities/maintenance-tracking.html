1. 활동 목적과 ISA-95 위치

작업 대상, 자원, 상태, 위치, genealogy를 시간순으로 추적합니다. 설비의 예방보전, 고장보전, 점검, 수리 작업을 계획하고 실행하여 생산 중단과 품질 위험을 줄이는 영역입니다.

ISA-95 관점Maintenance Operations Management의 activity 중 하나로, Level 4의 계획과 Level 2/1의 실제 제어 사이에서 실행 가능한 업무 판단을 담당합니다.
학생에게 설명하는 비유계획표가 있어도 지금 실행할 수 있는지, 필요한 조건이 맞는지, 실행 결과를 어떻게 기록할지 정하지 않으면 현장은 움직이지 않습니다. 이 activity는 그 판단 규칙을 담당합니다.

현장 예시

  • PM due 계산
  • 고장 작업 오더 생성
  • 수리 담당자와 부품 배정
  • MTBF/MTTR 분석

2. 기능 범위

보전 운영 관리 - 추적는 아래 범위를 하나의 업무 서비스로 묶어 생각하면 이해가 쉽습니다. 각 범위는 요구사항, 화면, API, 테스트 케이스로 이어집니다.

범위업무 의미구현 산출물
1. 현재 위치와 상태 관리maintenance work order, equipment, spare part의 실행 조건을 표준화합니다.화면, API, 상태 테이블, 이력 테이블, 권한 정책으로 구현합니다.
2. 상태/위치 이력 기록보전 기술자, 설비, spare part, PM 절차서와 연결하여 현장 판단을 자동화합니다.화면, API, 상태 테이블, 이력 테이블, 권한 정책으로 구현합니다.
3. 분할, 병합, 대체, 재작업 관계 기록보전 기술자, 설비, spare part, PM 절차서와 연결하여 현장 판단을 자동화합니다.화면, API, 상태 테이블, 이력 테이블, 권한 정책으로 구현합니다.
4. 정방향/역방향 trace 조회보전 기술자, 설비, spare part, PM 절차서와 연결하여 현장 판단을 자동화합니다.화면, API, 상태 테이블, 이력 테이블, 권한 정책으로 구현합니다.

3. Activity DFD

이 DFD는 ISA-95 activity를 코드로 옮길 때의 기본 흐름입니다. 핵심은 입력을 바로 실행하지 않고 기준정보, 자원 상태, 권한, 품질 조건을 거쳐 상태와 이력을 남기는 것입니다.

단계처리 의미저장/검증 포인트
1. 보전 운영 관리 요청상위 계획, 현장 요청, 외부 시스템 이벤트가 들어오는 단계입니다.source system, correlation id, 수신 시각을 저장합니다.
2. 기준정보/자원 확인ISA-95 Level 3에서 검증, 판단, 실행 상태 전이를 수행합니다.상태, 이력, 오류 사유, 기준정보 revision을 남깁니다.
3. 상태와 위치 추적ISA-95 Level 3에서 검증, 판단, 실행 상태 전이를 수행합니다.상태, 이력, 오류 사유, 기준정보 revision을 남깁니다.
4. 상태와 이력 저장ISA-95 Level 3에서 검증, 판단, 실행 상태 전이를 수행합니다.상태, 이력, 오류 사유, 기준정보 revision을 남깁니다.
5. 성과/통합 피드백ERP, APS, KPI, 데이터 플랫폼 또는 다른 MOM activity로 결과를 넘깁니다.상태, 이력, 오류 사유, 기준정보 revision을 남깁니다.

ISA-95 객체 연결

Operations Request상위 계획 또는 현장 요청으로부터 생성되는 실행 요구입니다.
Operations Schedule언제 어떤 자원으로 실행할지 계획한 결과입니다.
Operations Performance실제로 수행된 시간, 수량, 자원, 품질 결과입니다.

6. 화면과 API 설계

현장 화면은 ISA-95 용어를 그대로 나열하기보다, 작업자가 지금 할 수 있는 action과 차단 사유를 명확하게 보여줘야 합니다.

현장 실행 화면현재 객체 상태, 가능 action, 차단 조건, 관련 기준정보 revision을 표시합니다.
관리자 화면업무 규칙, 기준정보, 예외 승인, 변경 이력을 관리합니다.
통합 APIERP, APS, SCADA, 데이터 플랫폼과 request/schedule/performance를 주고받습니다.

API 예시

POST /api/isa95/maintenance/tracking/commands GET /api/isa95/maintenance/tracking/current-state?objectId={id} GET /api/isa95/maintenance/tracking/history?from={date}&to={date}

8. 운영 체크리스트

  • 현재 상태와 마지막 정상 이벤트, 마지막 오류 이벤트를 한 화면에서 확인할 수 있다.
  • 모든 action은 실행자, 시각, 변경 전/후 상태, 사유, correlation id를 남긴다.
  • 외부 시스템 연동 실패 시 재처리 queue와 운영 알림이 있다.
  • 기준정보 변경 시 진행 중 작업과 미래 작업의 영향도를 조회할 수 있다.
  • 성과 분석과 추적 모델에서 이 activity의 이력을 재사용할 수 있다.

이 문서는 ANSI/ISA-95를 기반으로 MES/MOM 시스템 설계를 학습하기 위한 교육용 해설입니다. 공식 표준 조항을 대체하지 않으며, 실제 프로젝트에서는 최신 ISA-95 문서, 고객 URS, 사이트 표준, ERP/PLC/SCADA 연동 규격을 함께 검토해야 합니다.

1. 모델 목적

설비와 별도로 실제 자산의 구매, 설치, 교정, 보전, 수명주기 정보를 관리합니다.

ISA-95 모델은 화면 이름을 정하는 용도가 아니라 시스템 사이의 데이터 계약을 정하는 기준입니다. 같은 설비, 자재, 작업 요청을 ERP, MES, SCADA가 서로 다르게 해석하면 통합 비용이 커지므로 객체의 경계와 관계를 먼저 맞춰야 합니다.

2. 핵심 구조

객체역할수업식 해설
Physical Asset물리 자산설비, 계측기, 금형, 운반 장비 같은 추적 대상입니다.
Asset Class자산 유형동일한 관리 규칙을 공유하는 유형입니다.
Lifecycle수명주기구매, 설치, 운전, 이동, 폐기 단계를 표현합니다.
Maintenance Link보전 연결보전 활동과 자산 이력을 연결합니다.

3. 모델 DFD

단계의미모델링 포인트
1. Asset Class상위 개념 또는 입력 객체입니다.ID, parent 관계, revision, owner system, effective date를 관리합니다.
2. Asset관계, 계층, 상태 또는 능력을 해석하는 중간 모델입니다.ID, parent 관계, revision, owner system, effective date를 관리합니다.
3. Installation관계, 계층, 상태 또는 능력을 해석하는 중간 모델입니다.ID, parent 관계, revision, owner system, effective date를 관리합니다.
4. Calibration/PM관계, 계층, 상태 또는 능력을 해석하는 중간 모델입니다.ID, parent 관계, revision, owner system, effective date를 관리합니다.
5. Retirement하위 시스템이나 통합 메시지가 사용하는 결과입니다.ID, parent 관계, revision, owner system, effective date를 관리합니다.

6. 통합 관점

ERP계획, 품목, 주문, 원가와 연결되는 상위 기준정보를 제공합니다.
MES/MOM실행 상태, schedule, performance, genealogy를 관리합니다.
SCADA/PLC실제 설비 상태와 공정 데이터를 이벤트로 제공합니다.

7. 테스트 시나리오

테스트 ID시나리오기대 결과
TC-01자산 설치 이력객체 관계, ID 매핑, revision, 통합 메시지가 설계와 일치해야 합니다.
TC-02교정 만료 경고객체 관계, ID 매핑, revision, 통합 메시지가 설계와 일치해야 합니다.
TC-03자산-설비 매핑 변경객체 관계, ID 매핑, revision, 통합 메시지가 설계와 일치해야 합니다.
TC-04폐기 자산 사용 차단객체 관계, ID 매핑, revision, 통합 메시지가 설계와 일치해야 합니다.

8. 운영 체크리스트

  • 객체 ID와 외부 시스템 ID 매핑표가 있다.
  • 기준정보 owner system과 변경 승인 절차가 명확하다.
  • 모델 변경 시 영향받는 schedule, request, performance를 조회할 수 있다.
  • 통합 메시지 실패를 재처리할 수 있다.
  • 과거 실적을 당시 모델 revision 기준으로 해석할 수 있다.
